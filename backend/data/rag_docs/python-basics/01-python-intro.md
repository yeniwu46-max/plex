# 模块一：Python 入门

本模块建立 Python 程序的基本读写习惯：程序如何按顺序执行、如何用注释说明意图、如何用变量保存数据，以及如何与用户完成输入输出交互。学完后应能独立编写“读入—计算—输出”的短脚本。

## 1. 程序结构
`document_id: python-stage1-program-structure`

Python 程序默认自上而下顺序执行：解释器从文件第一行开始，遇到语句就执行，遇到定义（如函数）则先登记再继续。代码块不靠花括号，而靠**缩进**界定；官方风格为每层缩进四个空格，同一层级必须对齐。入口约定常用 `if __name__ == "__main__":`，使文件既可被导入为模块，也可作为脚本直接运行。初学者应养成“先想清楚输入、处理、输出三步，再落笔写代码”的习惯，避免边写边猜。

- 概念：Python 程序通常自上而下顺序执行，代码块依赖四个空格缩进而非花括号；同一代码块缩进必须一致，否则会触发 IndentationError。脚本可作为模块被导入，此时 `__name__` 不是 `"__main__"`；若希望仅在直接运行时执行演示逻辑，应把入口写在 `if __name__ == "__main__":` 之下。良好的程序结构把“读入、计算、输出”分层，便于阅读与调试，也为后续函数封装打下基础。

### 正例代码

```python
def main():
    name = "PLEX"
    major = "软件工程"
    print(name)
    print(major)


if __name__ == "__main__":
    main()
```

- 正例：先完成赋值再输出，例如 `name = "PLEX"` 后执行 `print(name)`；入口放在 `if __name__ == "__main__":` 下，保证导入模块时不会自动跑演示代码。

### 反例与易错点

```python
# 错误：无故缩进，触发 IndentationError
  print("hello")

print("world")
    print("oops")  # 与上一行不在同一逻辑块却缩进
```

- 反例：在没有 `if/for/def` 等需要代码块的地方随意缩进，或混用 Tab 与空格，会触发 `IndentationError`；把业务逻辑散落在模块顶层而不用入口保护，导入时也会副作用执行。
- 常见错误：中英文标点混用（全角冒号、逗号）、缩进层级不一致、变量使用前未定义、把逻辑写乱导致“先用后算”。

### 练习

- 基础题：编写程序依次输出你的姓名和专业（各占一行）。
- 答案要点：使用两次 `print`，或一次 `print` 配合换行字符；确保无多余缩进；字符串用英文引号包裹。
- 进阶题：把“输入姓名与专业、拼接提示语、输出结果”分成三个清晰步骤（可用注释或空行分隔），最后用 `if __name__ == "__main__":` 作为入口。
- 进阶答案要点：`input` 读取 → 字符串拼接或 f-string → `print`；入口判断保证结构清晰。

### 相关知识点

- 前置知识点：无（本课起点）。
- 后续知识点：`comment`（注释）、`var`（变量与类型）、`io`（输入输出）。
- 来源：Python 官方教程“Whetting Your Appetite”“More Control Flow Tools”。

## 2. 注释
`document_id: python-stage1-comments`

注释用于向人说明“代码为什么这样写”，不参与运算。单行注释以 `#` 开头，可独占一行，也可写在语句末尾。三引号字符串（`"""..."""` 或 `'''...'''`）若出现在模块、类、函数体开头，常作为**文档字符串（docstring）**，可用 `help()` 查看；若随便包住一段“想注释掉的代码”，实际会创建字符串对象，既不是真正注释，也会浪费资源。注释应简洁、与代码同步；过时注释比没有注释更危险。切勿在注释中写入密码、令牌等敏感信息。

- 概念：`#` 之后到行末为单行注释，解释器会忽略；文档字符串用于说明模块、函数或类的用途、参数与返回值，不等同于“批量注释”。好的注释解释意图、约束与边界，而不是逐行翻译语法。删除失效代码应交给版本控制，不要用大段注释堆历史。编写函数时，docstring 比零散行尾注释更利于团队协作与工具生成帮助信息。

### 正例代码

```python
def celsius_to_fahrenheit(celsius):
    """将摄氏温度转换为华氏温度。

    参数:
        celsius: 摄氏度，允许为 float。
    返回:
        对应的华氏度。
    """
    # 公式：F = C * 9/5 + 32
    return celsius * 9 / 5 + 32


total = 0  # 累计已录入的分数之和
```

- 正例：`total = 0  # 累计分数` 用行尾注释说明变量含义；函数开头用 docstring 写清参数与返回值。

### 反例与易错点

```python
# 错误：用三引号“注释掉”大段代码，实际创建了未使用的字符串
"""
password = "secret-key-should-not-be-here"
old_logic()
"""

# 错误：注释与代码不一致
score = score + 10  # 减去附加分（实际在加分）
```

- 反例：用三引号包住大量代码会创建字符串字面量，不能替代版本控制，也容易误留密钥；注释写“减去”而代码在“加上”，会误导维护者。
- 常见错误：注释与代码不一致、大段保留失效代码、在注释或源码中泄露密钥、把 docstring 当成可执行配置。

### 练习

- 基础题：为一个温度转换程序（摄氏转华氏）补充必要注释与一行 docstring。
- 答案要点：公式旁写简短说明；函数 docstring 含参数与返回值；不要注释掉整段可运行逻辑。
- 进阶题：为“计算圆面积”函数编写包含参数、返回值与单位说明的文档字符串，并用 `help(函数名)` 在交互环境查看。
- 进阶答案要点：docstring 放在函数体首行；写明 `radius` 含义与返回面积；避免空 docstring。

### 相关知识点

- 前置知识点：`intro`（程序结构）。
- 后续知识点：`var`（变量与类型）、`func`（函数）。
- 来源：Python 官方教程“An Informal Introduction to Python”，PEP 257。

## 3. 变量与类型
`document_id: python-stage1-variables-types`

变量是对象的名字：赋值语句把名字绑定到对象上，并不预先声明类型。常用基础类型包括整数 `int`、浮点数 `float`、字符串 `str`、布尔值 `bool`。可用 `type(x)` 查看类型，用 `int()` / `float()` / `str()` / `bool()` 做转换。注意：字符串与数字不能直接做算术；`"90" + 10` 会报 `TypeError`，应先 `int("90")`。命名应有意义，避免覆盖 `list`、`str`、`sum` 等内置名。浮点运算存在精度误差，不宜用 `==` 直接判断两个计算结果是否精确相等，可比较差值是否小于某一阈值。

- 概念：变量通过赋值绑定对象，无需事先声明类型；同一名字可先后绑定不同类型的对象。基础类型中 `int`/`float` 用于数值计算，`str` 用于文本，`bool` 只有 `True`/`False`。类型决定可执行的运算：字符串拼接用 `+`，数值相加也用 `+`，但两侧类型必须匹配或先转换。理解“名字与对象分离”有助于避免修改可变对象时的意外共享；初学阶段先掌握不可变的基础类型与显式转换即可。

### 正例代码

```python
age = 18
height = 1.72
passed = True
label = "学员"

score_text = "90"
score = int(score_text)
print(score + 10)  # 100
print(type(age), type(height), type(passed))
```

- 正例：`age = 18`、`height = 1.72`、`passed = True` 分别绑定整型、浮点与布尔；需要运算时先把字符串转为 `int`。

### 反例与易错点

```python
score = "90"
print(score + 10)  # TypeError：str 与 int 不能相加

# 错误：覆盖内置名后无法再调用内置函数
list = [1, 2, 3]
# list(range(3))  # TypeError：list 已不是类型

# 危险：浮点直接判等
print(0.1 + 0.2 == 0.3)  # 常为 False
```

- 反例：`score = "90"; print(score + 10)` 产生类型错误，应先 `int(score)`；覆盖内置名、把 `=` 当作比较（比较应使用 `==`）都会导致隐蔽缺陷。
- 常见错误：覆盖内置名、把赋值 `=` 当作相等比较、浮点数直接判等、忘记把输入字符串转为数值。

### 练习

- 基础题：读取两个整数（可先用字面量模拟），输出它们的和与平均值（平均值可用浮点除法）。
- 答案要点：`a + b` 求和；平均值 `(a + b) / 2` 或 `/ 2.0`；注意类型为数值而非字符串。
- 进阶题：从字符串形式的用户输入安全转换为整数，若非法则给出提示且不崩溃（可结合后续异常处理预习 `try/except`）。
- 进阶答案要点：`int(text)` 包在 `try` 中捕获 `ValueError`，提示“请输入整数”。

### 相关知识点

- 前置知识点：`intro`（程序结构）、`comment`（注释）。
- 后续知识点：`io`（输入输出）、`ops`（运算与表达式）。
- 来源：Python 官方教程“Using Python as a Calculator”“Data Structures”。

## 4. 输入输出
`document_id: python-stage1-input-output`

`input(prompt)` 从标准输入读取一行，**始终返回字符串**。若需要数字，必须显式转换：`int(input(...))` 或 `float(input(...))`。`print` 可一次输出多个对象，默认以空格分隔、以换行结尾；可用 `sep`、`end` 参数调整。现代写法推荐 f-string：`f"明年 {age + 1} 岁"`，在花括号内可写表达式。格式化小数可用 `{value:.2f}`。交互程序要考虑用户输错类型的情况，至少在题目要求范围内做转换与提示。

- 概念：`input()` 负责读入，返回值类型固定为 `str`，因此参与算术前必须转换；`print()` 负责写出，支持多个参数以及 `sep`、`end` 控制分隔与结尾。f-string 把表达式嵌入字符串，可读性优于多次拼接。输入输出是“读入—计算—输出”模式的两端：读入要校验类型与范围，输出要控制格式（小数位、单位、对齐），这样程序才对人和后续文件处理都友好。

### 正例代码

```python
age = int(input("年龄："))
print(f"明年 {age + 1} 岁")

radius = float(input("半径："))
area = 3.14159 * radius ** 2
print(f"面积约为 {area:.2f}")

print("总分", 90, 85, sep="=", end="!\n")
```

- 正例：`age = int(input("年龄："))` 后用 f-string 输出；面积用 `{area:.2f}` 保留两位小数。

### 反例与易错点

```python
# 错误：字符串与整数相加
print(input("数字：") + 1)

# 错误：格式化占位与参数不匹配（旧式 % 用法示例）
# print("成绩 %d" % "优秀")

name = input("姓名：")
print("你好", name)  # 默认空格；若不想要空格需改 sep
```

- 反例：`input("数字：") + 1` 会把字符串与整数相加而报错；忘记 `int`/`float` 转换是最常见问题。
- 常见错误：忘记类型转换、f-string 花括号写错、`sep`/`end` 误用导致多余空格或粘连、对 `input` 返回值直接算术。

### 练习

- 基础题：输入圆半径，输出保留两位小数的面积（可取 π=3.14159）。
- 答案要点：`float(input(...))`；`area = pi * r * r`；`print(f"{area:.2f}")`。
- 进阶题：输入三门成绩（整数），输出总分、平均分（保留一位小数）以及是否及格（平均分≥60）。
- 进阶答案要点：三次 `int(input)`；求和与平均；用 `if` 判断及格（可先输出布尔或文字，分支细节见条件模块）。

### 相关知识点

- 前置知识点：`var`（变量与类型）。
- 后续知识点：`ops`（运算与表达式）、`cond`（条件分支）、`file`（文件操作）。
- 来源：Python 官方教程“Input and Output”。
