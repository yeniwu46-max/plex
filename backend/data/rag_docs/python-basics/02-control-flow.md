# 模块二：控制结构

本模块学习如何用表达式描述计算与判断，用 `if/elif/else` 分支、用 `for`/`while` 重复执行，并用 `range` 生成整数序列。掌握后可编写带逻辑判断与批量处理的小程序。

## 5. 运算与表达式
`document_id: python-stage2-operators`

表达式由运算对象与运算符组成，求值后得到一个结果。算术运算包括 `+ - * / // % **`：`/` 真除得浮点，`//` 向下取整除，`%` 取余，`**` 乘方。比较运算 `== != < > <= >=` 得到布尔值。逻辑运算 `and`、`or`、`not` 用于组合条件；注意不要与位运算 `& | ^` 混淆。运算符有优先级，拿不准时加括号，既正确又清晰。复合判断如“成年且及格”应写成 `age >= 18 and score >= 60`。

- 概念：算术、比较、逻辑运算共同组成表达式，括号优先于默认优先级。`/` 与 `//` 语义不同，混用会导致类型或数值偏差；`%` 常用于奇偶判断与周期性问题。逻辑运算对布尔值短路求值：`and` 左假则不算右，`or` 左真则不算右。书写多条件时用括号明确意图，避免依赖难记的优先级表。表达式是条件分支与循环条件的基础，也是后续统计、查找算法中判断语句的核心。

### 正例代码

```python
age = 20
score = 75
eligible = age >= 18 and score >= 60
print(eligible)  # True

n = 14
is_even = (n % 2 == 0)
print(is_even)

# 阶梯计价示意：满 100 打九折
amount = 120
pay = amount * 0.9 if amount >= 100 else amount
print(pay)
```

- 正例：`eligible = age >= 18 and score >= 60` 组合比较与逻辑运算；用 `n % 2 == 0` 判断偶数。

### 反例与易错点

```python
a, b = 1, 2
# 错误倾向：用位运算 & 连接比较（优先级与语义都易错）
print(a > 0 & b > 0)  # 实际按位运算规则结合，结果常不符合直觉

# 应使用：
print(a > 0 and b > 0)

print(7 / 2)   # 3.5
print(7 // 2)  # 3
```

- 反例：`a > 0 & b > 0` 混用位运算与比较，优先级导致语义错误；应使用 `and`。
- 常见错误：混淆 `/` 与 `//`、忘记 `%` 的用途、复杂表达式不加括号、用 `=` 代替 `==`。

### 练习

- 基础题：判断一个整数是否为偶数，输出 `True` 或 `False`（或中文“是/否”）。
- 答案要点：`n % 2 == 0`；注意负数在 Python 中取余规则仍可用于奇偶判断。
- 进阶题：输入订单原价，满 100 打 9 折、满 200 打 8 折（取最高档），计算实付金额。
- 进阶答案要点：先判断 `>= 200`，再 `>= 100`，否则原价；折扣用乘法，注意分支顺序。

### 相关知识点

- 前置知识点：`var`（变量与类型）、`io`（输入输出）。
- 后续知识点：`cond`（条件分支）、`loop`（循环结构）。
- 来源：Python 官方语言参考“Expressions”。

## 6. 条件分支
`document_id: python-stage2-condition`

`if` 语句按条件选择执行路径：`if` 后写表达式，为真则执行缩进块；可用若干 `elif` 继续尝试；最后 `else` 承接其余情况。分支自上而下匹配，**第一个为真的分支执行后其余跳过**。因此多级分数段必须从高到低（或从细到粗）排列，否则高分会被宽松条件截获。每个分支标题行末尾需要英文冒号 `:`，分支体必须缩进。边界值（如刚好 60 分）要在题意中明确用 `>=` 还是 `>`。

- 概念：`if/elif/else` 按顺序匹配条件，第一个为真的分支执行，其余不再判断。它把程序从直线脚本变成可决策流程，是业务规则（及格、折扣、闰年、奖学金）的主实现手段。条件表达式通常由比较与逻辑运算构成；嵌套 `if` 能表达更复杂规则，但过深嵌套会降低可读性，可优先用 `elif` 拉平。写分支时同步考虑边界与默认分支，避免“静默什么都不做”。

### 正例代码

```python
score = 92
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "P"
else:
    grade = "F"
print(grade)


def is_leap(year: int) -> bool:
    return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
```

- 正例：分数等级从高到低判断：`>= 90` 再 `>= 60` 再 `else`；闰年用“能被 400 整除，或能被 4 整除但不能被 100 整除”。

### 反例与易错点

```python
score = 95
# 错误顺序：先宽松后严格，高分被截获
if score >= 60:
    grade = "P"
elif score >= 90:
    grade = "A"  # 永远走不到
else:
    grade = "F"
```

- 反例：先判断 `score >= 60` 再判断 `score >= 90`，高分会被前一分支截获，导致等级错误。
- 常见错误：漏写冒号、缩进错误、边界条件遗漏、`elif` 条件互斥未设计好、用赋值 `=` 当条件。

### 练习

- 基础题：输入年份，判断是否为闰年并输出结果。
- 答案要点：`year % 400 == 0` 或 `(year % 4 == 0 and year % 100 != 0)`；注意世纪年。
- 进阶题：根据成绩与竞赛获奖情况计算奖学金等级（自行设定 2～3 条清晰规则），输出等级名称。
- 进阶答案要点：规则写成互斥或有序的 `if/elif`；先处理最高等级；对缺省情况给 `else`。

### 相关知识点

- 前置知识点：`ops`（运算与表达式）、`io`（输入输出）。
- 后续知识点：`loop`（循环结构）、`range`（range）。
- 来源：Python 官方教程“if Statements”。

## 7. 循环结构
`document_id: python-stage2-loop`

循环用于重复执行相似操作。`for` 适合遍历可迭代对象（字符串、列表、`range` 等）；`while` 适合“条件成立就继续”、次数不事先固定的场景。`break` 立即结束整个循环；`continue` 跳过本轮剩余语句进入下一轮。累加、计数时，初始化必须放在循环外；循环体内要更新让循环趋向结束的变量，否则 `while` 可能死循环。遍历时不要随意改动正在遍历的序列结构（增删元素），容易跳过或重复。

- 概念：`for` 遍历可迭代对象，`while` 在条件为真时重复执行；`break` 结束循环，`continue` 跳过本轮。循环把“批处理”从手工复制粘贴中解放出来，是求和、查找、读写多行的基础。选择 `for` 还是 `while` 看迭代对象是否明确：有序列用 `for`，否则用 `while` 并显式更新状态。关注循环不变量（每轮结束后哪些量保持正确）有助于减少 off-by-one 错误。

### 正例代码

```python
numbers = [3, 5, 7]
total = 0
for value in numbers:
    total += value
print(total)  # 15

# while：读到 -1 结束
# scores = []
# while True:
#     x = int(input("成绩(-1结束)："))
#     if x == -1:
#         break
#     scores.append(x)
```

- 正例：`total = 0` 放在循环外，循环内 `total += value`；用 `break` 响应结束哨兵值。

### 反例与易错点

```python
count = 0
while count < 10:
    print(count)
    # 忘记 count += 1 → 死循环

total = 0
for value in [1, 2, 3]:
    total = 0  # 错误：每轮重置
    total += value
```

- 反例：`while count < 10:` 内不更新 `count` 会形成死循环；把累计变量放在循环内重置会导致结果只剩最后一项。
- 常见错误：循环变量覆盖、累计值放在循环内重置、边界多一次或少一次、`break`/`continue` 用错层级。

### 练习

- 基础题：输出 1 到 100 中所有 3 的倍数（可借助 `range` 或 `%`）。
- 答案要点：遍历 1..100，`if n % 3 == 0: print(n)`；或 `range(3, 101, 3)`。
- 进阶题：循环读取若干成绩，输入 `-1` 结束，输出平均分；若没有任何有效成绩则提示。
- 进阶答案要点：`while` + `break`；累加与计数；计数为 0 时避免除零。

### 相关知识点

- 前置知识点：`cond`（条件分支）、`ops`（运算与表达式）。
- 后续知识点：`range`（range）、`list`（列表）、`algo-sum`（求和与统计）。
- 来源：Python 官方教程“for Statements”“break and continue Statements”。

## 8. range
`document_id: python-stage2-range`

`range` 表示整数等差序列，常与 `for` 联用。形式为 `range(stop)` 或 `range(start, stop[, step])`，规则是**左闭右开**：包含 `start`，不包含 `stop`。`step` 可为负以实现递减。`range` 本身惰性，需要列表时才 `list(range(...))`。用它生成下标时，常见写法是 `for i in range(len(seq))`，但能直接 `for x in seq` 时更清晰。步长不能为 0；负步长时要保证 `start` 在 `stop` “上方”，否则序列为空。

- 概念：`range(start, stop, step)` 产生左闭右开的整数序列，`stop` 不包含在结果中。它是计数型循环的标准工具，能精确控制起止与步长，常用于固定次数重复、下标访问与构造简单表格（如九九乘法表）。理解右开区间可避免“少循环一次”的经典错误；与列表长度配合时，合法下标是 `0 .. len-1`，对应 `range(len(xs))`。

### 正例代码

```python
print(list(range(1, 6)))       # [1, 2, 3, 4, 5]
print(list(range(10, 0, -1)))  # 10 到 1

for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}*{i}={i * j}", end="\t")
    print()
```

- 正例：`list(range(1, 6))` 得到 `[1, 2, 3, 4, 5]`；`range(10, 0, -1)` 输出 10 到 1；嵌套 `range` 可打印九九表。

### 反例与易错点

```python
# 期待 1..5 却写成 range(1, 5) → 只有 1..4
print(list(range(1, 5)))

# 负步长方向错误 → 空序列
print(list(range(1, 10, -1)))  # []

# range(5, 0) 无负步长 → []
```

- 反例：用 `range(1, 5)` 期待包含 5，会少执行一次；负步长却让 `start < stop` 会得到空序列。
- 常见错误：步长为零（`ValueError`）、负步长方向错误、索引范围与列表长度不匹配导致越界。

### 练习

- 基础题：使用 `range` 输出从 10 到 1 的整数（降序）。
- 答案要点：`for i in range(10, 0, -1): print(i)`；注意止于 0 开区间。
- 进阶题：用嵌套 `range` 输出九九乘法表（下三角或全表均可，格式对齐加分）。
- 进阶答案要点：外层 `i`，内层 `j`；`j` 的上界与 `i` 相关；用 `end` 控制同行输出。

### 相关知识点

- 前置知识点：`loop`（循环结构）。
- 后续知识点：`list`（列表）、`algo-sum`（求和与统计）、`algo-search`（线性查找）。
- 来源：Python 官方教程“The range() Function”。
