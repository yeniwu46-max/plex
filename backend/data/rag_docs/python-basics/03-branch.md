# 模块三：分支结构

本模块让程序从“一条道走到黑”变成“会看情况做决定”：先用 `if` 处理只在特定条件下才做的事，再用 `if-else` 处理二选一，接着用 `if-elif-else` 串联多个区间，最后掌握嵌套分支与 `and`/`or`/`not` 复合条件。学完后应能把“成绩等第、闰年判断、阶梯计价、准入资格”这类业务规则准确翻译为代码。

## 1. 单分支与双分支
`document_id: python-branch-if`

`if` 是最基本的判断语句：`if` 后面写一个条件表达式，条件为真就执行下面缩进的代码块，为假就整块跳过，这叫单分支。若“真”和“假”两种情况都要处理，就再加一个 `else`，构成双分支——两条路必有且只有一条被执行。语法上有两个硬性要求：`if` 与 `else` 所在的行末尾必须有英文冒号 `:`，其下的代码块必须缩进（官方风格四个空格）。初学者最容易卡在三个地方：漏写冒号、分支体忘记缩进、以及把赋值 `=` 误当成相等比较 `==`。

- 概念：`if 条件:` 只在条件为真时执行缩进块，`else:` 承接条件为假的情况；两者合起来覆盖全部可能，因此双分支不会出现“什么都没做”的情况。条件表达式通常由比较运算符 `== != > < >= <=` 构成，求值结果是布尔值 `True`/`False`。Python 还允许非布尔值直接作条件，此时按真假性判定：`0`、`0.0`、`""`、空列表 `[]`、`None` 视为假，其余非空非零对象视为真。冒号标记“下面是一个代码块”，缩进标记“这些语句属于该块”，两者共同替代了其他语言的花括号。单分支适合“额外补充一步处理”，双分支适合“二选一”，是后续多分支与循环条件的基础。

### 正例代码

```python
score = 72
if score >= 60:
    print("及格")            # 条件为真才执行这一块

age = 17
if age >= 18:
    print("成年")
else:
    print("未成年")          # 双分支必有一条被执行

# 空字符串在条件位置被视为假
name = ""
if name:
    print(f"你好，{name}")
else:
    print("姓名不能为空")
```

- 正例：`if score >= 60:` 行末有英文冒号，下一行 `print("及格")` 缩进四个空格；`if age >= 18: ... else: ...` 两个分支互补覆盖全部情况；`if name:` 直接利用空字符串为假的真假性判定。

### 反例与易错点

```python
score = 72
if score >= 60          # SyntaxError：行末漏写英文冒号
    print("及格")

if score >= 90:
print("优秀")            # IndentationError：分支体没有缩进

if score = 60:           # SyntaxError：条件里不能用赋值，应写 ==
    print("刚好及格")
```

- 反例：`if score >= 60` 漏掉冒号会直接抛 `SyntaxError`；分支体不缩进会抛 `IndentationError: expected an indented block`；`if score = 60:` 把赋值当判断同样是 `SyntaxError`，正确写法是 `if score == 60:`。

- 常见错误：行末漏写英文冒号、误用全角冒号 `：`、分支体不缩进或缩进不一致（Tab 与空格混用）、用 `=` 代替 `==` 作条件。

### 练习

- 基础题：输入一个整数成绩，若大于等于 60 输出“及格”，否则输出“不及格”。
- 答案要点：`score = int(input("成绩："))` 先转类型；`if score >= 60:` 配 `else:`；注意边界用 `>=` 而非 `>`。
- 进阶题：输入用户名与密码（可用字面量模拟），用户名非空且密码长度不少于 6 位时输出“登录成功”，否则分别提示“用户名不能为空”或“密码太短”。
- 进阶答案要点：先用 `if not name:` 拦截空用户名，再用 `if len(password) < 6:` 拦截短密码，最后 `else` 输出成功；注意用 `len()` 取长度而不是比较字符串大小。

### 相关知识点

- 前置知识点：`seq-expr`（运算与表达式）、`lang-var`（变量与类型）。
- 后续知识点：`branch-elif`（多分支 elif）、`branch-nested`（嵌套与复合条件）。
- 来源：Python 官方教程“4.1. if Statements”，PEP 8 缩进约定。

## 2. 多分支 elif
`document_id: python-branch-elif`

当情况不止两种，例如把百分制分数映射成“优良中及格不及格”五档，就需要 `if-elif-else` 串联。`elif` 是 `else if` 的缩写，可以连写任意多个，最后可选地跟一个 `else` 兜底。执行规则只有一条：自上而下依次判断，**第一个为真的分支执行完就跳出整条链**，后面的分支连判断都不做。正因如此，分支顺序直接决定结果对不对——区间判断必须按同一方向单调排列（配 `>=` 就从高到低，配 `<` 就从低到高），否则宽松条件会把本该进入严格分支的数据提前截获。

- 概念：`if/elif/else` 构成互斥的多路选择，条件按书写顺序求值，命中第一个为真的分支后其余全部跳过，因此“顺序”本身就是逻辑的一部分。用 `>=` 划分区间时必须从大到小排列（`>=90` → `>=80` → `>=60`），用 `<` 时必须从小到大排列，两种方向不可混用；一旦顺序错乱，程序不会报错，只会静默给出错误答案，这类 bug 最难发现。`else` 是兜底分支，负责所有未被前面条件覆盖的情况；省略 `else` 时若所有条件都不成立，整条链什么也不做，可能留下未赋值的变量或上一轮的旧值。写多分支时应先在纸上把区间边界列清楚，确认相邻区间既不重叠也不留缝。

### 正例代码

```python
score = 85
if score >= 90:
    grade = "优"
elif score >= 80:            # 走到这里说明已确定 score < 90
    grade = "良"
elif score >= 70:
    grade = "中"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"         # else 兜底，任何分数都能得到结果
print(grade)                 # 良

bmi = 22.5
if bmi < 18.5:
    level = "偏瘦"
elif bmi < 24:               # 用 < 判断则必须从小到大排列
    level = "正常"
else:
    level = "偏重"
print(level)                 # 正常
```

- 正例：等第判断用 `>=` 且从 `score >= 90` 到 `score >= 60` 从严到宽排列，每个 `elif` 都隐含了“前面条件都不成立”这一前提；BMI 判断改用 `<`，就必须反过来从小到大排列；两段都用 `else` 兜底，保证变量一定被赋值。

### 反例与易错点

```python
score = 95
if score >= 60:
    grade = "及格"
elif score >= 80:
    grade = "良"             # 永远走不到：95 已被上一条截获
elif score >= 90:
    grade = "优"             # 永远走不到
print(grade)                 # 及格 —— 结果错误但程序不报错

level = ""
if score >= 90:
    level = "优"
elif score >= 60:
    level = "及格"
# 缺少 else：若 score 为 50，level 仍是空串，静默出错
```

- 反例：把 `score >= 60` 放在最前面，等于给所有及格分数都发了“及格”，后面的 `>= 80`、`>= 90` 成了死代码，程序不抛异常却输出错误等第，正确做法是把最严格的 `score >= 90` 放第一位；第二段漏写 `else`，落在区间外的数据会保留初始值或旧值。

- 常见错误：区间顺序从宽到严导致高分被截获、相邻区间边界重叠或留缝、漏写 `else` 兜底、把 `elif` 误写成多个独立的 `if`（导致多个分支同时执行）、`elif` 拼写成 `else if`。

### 练习

- 基础题：输入百分制成绩，按 90/80/70/60 四条界线输出“优/良/中/及格/不及格”五档等第。
- 答案要点：`if score >= 90` 开头，依次用 `elif` 递减到 `>= 60`，最后 `else` 输出“不及格”；顺序必须从高到低。
- 进阶题：输入订单原价，满 200 打 8 折、满 100 打 9 折、不满 100 原价，输出实付金额（保留两位小数），并对负数输入给出提示。
- 进阶答案要点：先用 `if amount < 0:` 拦截非法输入，再按 `>= 200` → `>= 100` → `else` 从高到低取最高档折扣；折扣用乘法 `amount * 0.8`，输出用 `f"{pay:.2f}"`。

### 相关知识点

- 前置知识点：`branch-if`（单分支与双分支）、`seq-expr`（运算与表达式）。
- 后续知识点：`branch-nested`（嵌套与复合条件）、`loop-for`（for 与 range）。
- 来源：Python 官方教程“4.1. if Statements”。

## 3. 嵌套与复合条件
`document_id: python-branch-nested`

真实规则常常是多维的：“二月且是闰年才有 29 天”“成年且成绩及格才能领证书”。表达这类规则有两条路：一是**嵌套**，在一个分支体内部再写一层 `if`，逐层收窄；二是**复合条件**，用 `and`、`or`、`not` 把多个判断组合成一个表达式。两者常可互相改写：`if A: if B:` 等价于 `if A and B:`。选择的标准是可读性——只关心“同时成立”时用 `and` 拉平，需要在中间层给出不同反馈时才嵌套。初学者最容易卡在把 `and` 误写成 `or`（条件被意外放宽），以及嵌套超过三层后自己都分不清哪个 `else` 配哪个 `if`。

- 概念：嵌套分支指在 `if`/`elif`/`else` 的代码块内部再写分支，由缩进层级决定归属关系，每深一层就意味着“外层条件已经成立”这一前提。复合条件用逻辑运算符组合判断：`and` 要求两侧同时为真，`or` 只需一侧为真，`not` 取反。逻辑运算是短路求值：`and` 左侧为假就不再计算右侧，`or` 左侧为真就不再计算右侧，这个特性常用来先判断“安全前提”再访问数据。`and` 的优先级高于 `or`，`not` 高于两者，混写时应加括号明确意图而不是依赖优先级表。Python 还支持链式比较 `0 <= score <= 100`，比 `score >= 0 and score <= 100` 更简洁。工程上建议嵌套不超过两三层，能用 `and` 合并或用 `elif` 拉平的就不要嵌套，必要时可提前 `return` 或先拦截非法输入以减少层级。

### 正例代码

```python
year, month = 2024, 2
if month == 2:
    # 嵌套：外层已确定是二月，内层再判断闰年
    if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
        days = 29
    else:
        days = 28
elif month in (1, 3, 5, 7, 8, 10, 12):
    days = 31
else:
    days = 30
print(days)                  # 29

age, score = 20, 75
if age >= 18 and score >= 60:    # 复合条件把两层嵌套拉平成一行
    print("可以领取证书")
if not (0 <= score <= 100):       # 链式比较配 not 做范围校验
    print("分数超出范围")
```

- 正例：闰年判断把 `or` 与 `and` 的组合用括号写清优先级，`year % 400 == 0 or (...)` 中的括号让“能被 4 整除但不能被 100 整除”成为一个整体；`if age >= 18 and score >= 60:` 用一行复合条件替代了两层嵌套；`not (0 <= score <= 100)` 用链式比较表达区间校验。

### 反例与易错点

```python
age, score = 20, 55
# 错误：本该 and 却写成 or，条件被放宽，未及格者也通过
if age >= 18 or score >= 60:
    print("可以领取证书")

# 错误：嵌套过深且内层漏 else，60~89 分没有任何输出
if age >= 18:
    if score >= 60:
        if score >= 90:
            print("优秀毕业")

print(not score == 100)      # True：== 优先于 not，等价于 not (score == 100)
```

- 反例：把 `and` 写成 `or` 后，只要成年就能拿证书，业务规则被悄悄放宽，程序不报错但结果错误，应改回 `and`；三层嵌套中最内层只写了 `if` 没写 `else`，60 到 89 分的情况静默落空，正确做法是用 `elif` 拉平或补齐 `else`。

- 常见错误：`and` 与 `or` 混淆、`not` 的作用范围未加括号、嵌套层级过深导致 `else` 配错 `if`、内层分支漏写 `else` 造成静默落空、误用位运算 `&`/`|` 代替 `and`/`or`。

### 练习

- 基础题：输入年份，判断是否为闰年并输出结果（能被 400 整除，或能被 4 整除但不能被 100 整除）。
- 答案要点：条件写成 `year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)`；括号必须加，否则优先级会让 1900 这类世纪年判错。
- 进阶题：输入年份与月份，输出该月天数；月份不在 1～12 范围内时提示“月份非法”，二月需正确区分 28 天与 29 天。
- 进阶答案要点：先用 `if not (1 <= month <= 12):` 拦截非法月份，再用 `elif month == 2:` 内部嵌套闰年判断，其余月份用 `month in (1, 3, 5, 7, 8, 10, 12)` 归为 31 天、`else` 归为 30 天。

### 相关知识点

- 前置知识点：`branch-elif`（多分支 elif）、`seq-expr`（运算与表达式）。
- 后续知识点：`loop-while`（while 循环）、`loop-control`（break 与 continue）。
- 来源：Python 官方教程“5.7. More on Conditions”，Python 官方语言参考“Boolean operations”。
