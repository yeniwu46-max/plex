# 《Python 程序设计基础》课程知识库

## 用途

本目录是 PLEX 中国软件杯版本的初始课程知识库，限定为一门完整课程，供以下能力使用：

- 学生画像中的知识基础判断。
- 多智能体资源生成。
- 驿站 RAG 辅导。
- 个性化路径和资源推荐。
- 内容引用与防幻觉审核。

## 课程结构

| 模块 | 文件 | 知识点 |
|---|---|---|
| Python 入门 | `01-python-intro.md` | 程序结构、注释、变量与类型、输入输出 |
| 控制结构 | `02-control-flow.md` | 运算与表达式、条件分支、循环结构、`range` |
| 数据组织 | `03-data-structures.md` | 字符串、列表、字典、函数 |
| 文件与算法实践 | `04-functions-practice.md` | 文件操作、异常处理、求和统计、线性查找 |

共 4 个模块、16 个知识点。

## 每个知识点的最低内容

- [ ] 概念讲解
- [ ] 正确示例
- [ ] 错误示例
- [ ] 常见错误
- [ ] 基础练习
- [ ] 进阶练习
- [ ] 资料来源

## 完整性状态

16 个知识点均已有独立章节、稳定且唯一的 `document_id`，并包含概念、正反例、常见错误、基础题、进阶题和来源。运行以下命令验证契约：

```bash
python scripts/verify_knowledge_base.py
```

仍需继续增强的内容：为全部练习补充答案与解析、执行文档代码样例、将文档加载到真实 RAG 索引并评测检索命中率。
