学生端优化总结（2026-07-15）


本文档汇总 2026-07-15 对学生端（Vue 3 前端 + Flask 后端）的全部优化与修复。


一、试炼页 / 编程练习
================================================================================

1.1 布局（洛谷式三栏）
  - 左侧 Tab：题目（默认）| 答题记录 | 讨论
  - 右侧：代码编辑器、运行测试
  - 题目描述、样例、运行结果、小E 反馈入口均在左侧「题目」Tab
  - 主要文件：frontend/src/components/trial/PythonTrialWorkspace.vue

1.2 小E 反馈 · 按需触发
  - 运行测试不再自动弹出 AI 诊断
  - 用户点击「请小E 看看」才请求反馈，带 loading 态
  - API：POST /api/v1/agents/trial-feedback

1.3 小E 悬浮球恢复
  - 题目页右下角 TrialAiFloatingBall 已恢复

1.4 答题记录
  - 每次运行/提交追加：时间、用时、对错、错误原因
  - 主要文件：frontend/src/utils/trialMistakeLog.ts

1.5 讨论区
  - 留言、点赞、回复；展示头像、昵称、评论内容
  - GET  /api/v1/trial-comments?question_ref=xxx
  - POST /api/v1/trial-comments
  - POST /api/v1/trial-comments/:id/like

1.6 AI 反馈内容精简
  - 移除「下一步推荐」「本次代码学习闭环报告」、提示按钮
  - 诊断等区块改为可折叠
  - 学生端不展示智能体协作流程、Agent 名称、技术 trace


二、星轨学习
================================================================================

2.1 节点解锁：星轨节点默认全部可进入练习

2.2 进题修复
  - 进入练习前预加载导入题库
  - 优先使用 learning_core 导入题（lc-{id}）
  - 「开始编程试炼」按钮移入底部固定操作区，避免被遮挡
  - 主要文件：StarPathLabView.vue、StudentTrialPracticeView.vue

2.3 题目搜索
  - 顶部搜索题号（如 L0042）或关键词，点击跳转试炼页
  - GET /api/v1/student/practice-questions?q=关键词
  - GET /api/v1/student/practice-questions/{题号或id}


三、题库与题目数据


3.1 learning_core 导入
  - 数据：data/learning_core_import/learning_core_groups_masked_normal.sql
  - 脚本：backend/scripts/import_learning_core.py
  - 约 435 道编程题、8 班、307 用户

3.2 题号规范：字母 + 四位数字（如 P0001、L0042、R0123）

3.3 智能短标题：L0042 · 兔子算总分（题号 + 精简名，约 20 字内）

3.4 练习题 API：GET /api/v1/student/practice-questions


四、驿站助手（Messenger）
================================================================================

4.1 快捷提问（四个按钮独立逻辑，小E 口吻）
  - 诊断薄弱点：基于近 7 天错题
  - 推荐下一试炼：RAG + 题库匹配，提供「去练 题号·标题」快捷按钮
  - 规划修复路线 / 查看最近成长
  - API：POST /api/v1/agents/messenger-quick-action

4.2 文案人设：frontend/src/utils/xiaoEPersona.ts


五、成长档案 / 我的
================================================================================

5.1 成长页
  - 学习趋势与星域掌握同一行并排
  - 移除「探索倾向」「成就收藏」
  - 知识雷达右侧恢复「错题分析」环形图

5.2 「我的」：移除「学习画像」，重定向至成长档案


六、试炼场（探索舱）
================================================================================

6.1 模块重构
  - 「班级试炼场」→「试炼场」
  - 学生对战：随机 3 题，ACM 赛制
  - 模拟考试：6 题套卷，限时 120 分钟
  - 文案精简，不出现「蓝桥杯」字样

6.2 个性化资源生成：不展示 Agent 卡片，仅小E 进度提示


七、新增 / 变更 API
================================================================================

POST /api/v1/agents/trial-feedback          试炼页按需小E 反馈
POST /api/v1/agents/messenger-quick-action  驿站快捷按钮
GET  /api/v1/trial-comments                 评论列表
POST /api/v1/trial-comments                 发布/回复评论
POST /api/v1/trial-comments/:id/like        点赞
GET  /api/v1/student/practice-questions     练习题库（含搜索）
GET  /api/v1/student/practice-questions/:ref  单题详情


八、验收建议
================================================================================

1. 星轨学习 /student/star-path → 「开始编程试炼」可见可点
2. 试炼页：左侧 Tab、请小E 看看、讨论、答题记录
3. 顶部搜索题号/关键词 → 跳转
4. 驿站「推荐下一试炼」→ 快捷进题按钮
5. 成长档案双图并排 + 错题环形图
6. 试炼场：学生对战 / 模拟考试

本地启动：
  后端 cd backend && py -3 run.py  （http://127.0.0.1:5100）
  前端 cd frontend && npm run dev  （http://localhost:5180）
  评论表首次使用：flask db upgrade
  改后端后需重启后端
