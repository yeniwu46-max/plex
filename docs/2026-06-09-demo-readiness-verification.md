## 双画像证据

- `student001`：Python 零基础，偏好分步骤和生活化案例，兴趣为校园生活自动化。
- `student002`：具备 Python 基础，偏好先看代码和挑战题，兴趣为算法竞赛。
- 同一 `loop` 知识点下，两组资源在难度、讲解表达和实操场景上均不同。
- 两组均生成讲解文档、思维导图、分层题库、拓展阅读和代码实操。
- 所有资源均包含课程引用、实际后端和画像快照。

## 三角色彩排

两轮均通过以下 API 主线：

1. 学生更新七维画像。
2. 学生生成五类循环结构资源。
3. 学生提交错误的循环边界用例。
4. 系统产生画像更新建议。
5. 学生接受建议，画像版本递增。
6. 本地降级生成的拓展阅读进入教师待审核。
7. 教师填写审核说明并批准。
8. 学生刷新后可见全部五类资源。
9. 任务历史刷新后仍可查询。
10. 管理员登录与健康接口正常。

彩排命令：

```bash
cd backend
python manage.py seed-demo
python scripts/verify_demo_readiness.py
```

## 修复项

- **P1**：本地规则生成此前全部自动批准，教师审核页无法通过正常流程获得待审核内容。现在拓展阅读因无法独立核验扩展材料而以 `low_confidence` 进入审核。
- **P1**：`seed-demo` 在 `student002` 不存在时静默跳过其画像。现在命令会幂等创建第二演示学生。
