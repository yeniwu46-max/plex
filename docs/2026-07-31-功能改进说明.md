## 1. 首页统计卡弹窗（图1）

### 实现
- 点击「当前等级 / 累计 XP」→ 等级进度条、XP、升级历史
- 点击「连续探索」→ 本月练习热力图（绿 4 档：0 / 1–4 / 5–14 / 15–19 / ≥20 题）
- 点击「班级排名」→ 排名、累计解题数、等级、班级榜

### 数据来源
| 字段 | 来源 |
|------|------|
| 等级 / XP / 进度 | `IncentiveService.level_profile` + 用户表 |
| 升级历史 | `PointsLog` 累计 XP 跨等级阈值推算 |
| 热力图 | `TrialQuestionProgress` 按日统计 |
| 班级排名 | `ClassService.get_class_ranking` + 用户 profile |

### 改动文件
- `backend/app/services/student_progress.py` — `get_stat_details`
- `backend/app/routes/student_progress.py` — `GET /stat-details`
- `frontend/src/api/studentOverview.ts` — `fetchStatDetails`
- `frontend/src/views/StudentHomeView.vue` — 可点击统计卡 + `NModal`

## 6. 驿站助手（图6）

- **根因**：`StudentShellLayout` 用 `path.startsWith('/student/me')` 匹配，`/student/messenger` 被误判。

## 需人工介入清单

1. **重启后端 Flask**  
   使 `.env` 中 `DEEPSEEK_LEARNING_PATH_API_KEY` 与新路由生效。

2. **DeepSeek 网络**  
   学习路径建议、驿站工具、画像流式均依赖 DeepSeek；失败时会走本地规则/模板兜底。

3. **Ark 配图（可选）**  
   「生成知识图」配图需 `ARK_API_KEY`；未配置时仍返回 Mermaid 文本。

4. **语音输入**  
   需 HTTPS 或 localhost + 麦克风权限；Edge/Chrome 支持较好。

5. **资源生成全链路**  
   若仍 500，请查看响应 JSON 中 `message`（已包装具体异常）；确认 DB 迁移与知识点重建数据已就绪。

6. **生产密钥**  
   文档中涉及的 DeepSeek key 已在本地 `.env` 配置；生产环境请轮换密钥，勿提交 `.env` 到 git。
