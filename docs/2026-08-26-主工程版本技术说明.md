## 1. 本冻包含什么

相对 2026-07-29 已推送的提交，本机未入库的主工程能力一并写入本分支，主要包括：

| 块 | 说明 |
| --- | --- |
| 学生/教师体验闭环 | 首页统计卡弹窗、知识碎片折叠、试炼回星轨、驿站语音与工具、对话式画像追问。详见 [`2026-07-31-功能改进说明.md`](2026-07-31-功能改进说明.md)、[`2026-07-31-下午验收巡检.md`](2026-07-31-下午验收巡检.md) |
| 驿站质量 | 概念题先讲清再留思考题；低质反问熔断并换 DeepSeek；`test_messenger_quality.py` |
| 题库 | 旧 Mulberry/HydroOJ dump 清洗后的教师/管理预览：`/api/v1/problem-bank`、页面 `/teacher/problem-bank`。学生端暂不开放个人提交历史（`legacy_user_id` 对不齐当前账号） |
| 知识重建 | `backend/scripts/knowledge_rebuild/` 从五源抽题归一；`backend/data/rag_docs/python-basics/` 作为 RAG 文档 |
| 对战匹配 | `DuelMatchService` 按班级在线心跳组队，题池与前端 `classArenaQuestions` 对齐 |
| 教师在线 | `teacherPresence` API + 在线 Explorer 弹窗 |
| MySQL | `scripts/migrate_sqlite_to_mysql.py`、`start_mysql_admin.bat`；本地修复脚本不入库 |
| AI 使用说明 | [`AI使用报告-开源项目与API调用.md`](AI使用报告-开源项目与API调用.md)（DeepSeek / 星火 / TTS / Ark，无密钥） |

## 2. 运行口径

- 后端：`backend/start_backend.bat` 或 venv 下 `python run.py` → `http://127.0.0.1:5100`
- 前端：`frontend` 执行 `npm run dev` → **http://localhost:5180/**（华灿奖演示请用 5188 克隆，不要用本仓改皮肤）
- 账号：`student001` / `student123`，`teacher001` / `teacher123`

## 3. 明确不入库

- `backend/.env`、`backend/.env.spark.local`（密钥）
- 题库导入 `problem_bank_import/output/` 大 SQL/JSON
- Playwright 会话转储、`runtime/`、软著申请资料、本机 MySQL 修补脚本、`_debug_probe*`
