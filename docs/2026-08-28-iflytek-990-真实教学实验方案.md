# PLEX × 科大讯飞 990 真实教学实验方案

## 目的

验证“大模型 + 多智能体 + 个性化学习路径”是否改善 Python 课程学习效果，同时记录系统稳定性、教师工作量和学生接受度。实验结果必须来自真实学生、真实课程和可追溯日志，不使用合成结果替代。

## 设计

- 对象：至少 100 人次有效学习记录（可由多个班级或多轮课程累计）。
- 周期：前测 1 次 → 5–10 次系统学习活动 → 后测 1 次，建议持续 2 周。
- 对照：优先同课程平行班对照；若无法设置对照，采用同一学生前后测并明确标注局限。
- 记录：学生使用匿名 `participant_id`，不采集姓名、手机号等不必要身份信息。
- 干预：系统记录画像版本、知识点、推荐资源、Agent、RAG 引用、复习计划、教师工单及完成状态。

## 必采字段

见 `backend/data/experiments/iflytek990_event_template.csv`。每条事件必须包含 participant_id、阶段（pre/intervention/post）、题目/知识点、是否正确、学习时长、推荐是否接受、教师工单状态和时间戳。

## 统计口径

1. 前测/后测正确率：按 participant_id 配对计算，报告样本数、均值、标准差、中位数和提升百分点。
2. 推荐接受率：accepted recommendations / shown recommendations。
3. 复习完成率：completed SM-2 reviews / due SM-2 reviews。
4. 教师工作量：每名学生平均审核/干预分钟数。
5. 缺失与退出：单独报告，不从分母中静默删除。

## 合规与证据

- 实验开始前取得教师和学校/课程负责人同意，学生使用脱敏编号。
- 保留原始 CSV、统计脚本版本、系统导出日志、测评题目版本和教师签字/盖章证明。
- 报告中区分“系统日志测得”“问卷自报”和“人工观察”，不把模拟数据写成真实效果。

## 执行命令

```text
py -3 backend/scripts/analyze_iflytek990_experiment.py \
  --input backend/data/experiments/iflytek990_event_template.csv \
  --output backend/reports/iflytek-990-experiment-20260828.json
```

模板为空或有效人次不足 100 时，脚本会输出 `status=insufficient_real_data`，不会生成虚假的显著性结论。

脚本同时校验 CSV 字段、阶段值（`pre/intervention/post`）、必填时间戳、重复事件键和疑似手机号/身份证号等个人标识；校验失败时通过 `validation_passed=false` 明确阻断。效果报告额外输出提升值的标准差和中位数，避免只报告均值。
