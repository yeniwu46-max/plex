# 小E模式推荐与递进提示

## 范围

基于 `codex/auth-trial-readiness` 的实际源码实现，入口位于编程工作区的小E浮窗。
该基线只有旧版试炼教练；10月19日汇总文档中的 `TutorService`、`TeachingPlan`
和 `LearnerState` 实现未包含在该分支。因此新增独立的辅导服务，不假设这些模块存在。

## 使用方式

1. 打开编程题，编写代码并打开小E。
2. 查看推荐模式及理由，点击自动推荐或任一帮助模式后立即获取反馈，不需再次确认。
3. 思路检查需输入实际思路，报错解释需提供报错；缺少内容时小E直接提示补充。
4. 在同一困难上，主动点击“再具体一点”，按观察、验证、局部结构三阶段展开。
   直接选择局部伪代码也不会跳过前两阶段。
5. 修改代码后重新判断，历史反馈标注为旧代码；切题、切账号清空当前辅导上下文。
6. 请求失败时“重试原请求”保持原编号和代码快照；提示展示确认失败时可单独重试确认。

原有模型自由问答和报错/质量/优化教练保留在“自由问答”和“其他辅导”入口。
本次新增的分阶段控制不代表旧接口均已采用同样的约束。

## 决策与生成

- 有报错或静态语法问题优先推荐报错解释；有实际思路优先推荐思路检查；
  普通求助从下一步提示开始；已展示验证方法后建议局部结构支架。
- 推荐由确定性规则生成，允许手动覆盖；不声称使用训练得到的模式分类器。
- 提示优先使用已有兼容模型配置生成，然后进行独立的一轮模型审核。
  无配置、超时、格式异常、代码块、重复候选或审核不通过时使用规则提示。
- 模型审核不构成正确性或零泄题保证，尚无教师标注的教学效果结论。
- 自测报错只作为用户提供的上下文；服务不声称执行代码，不增加成绩、掌握度或正式作答记录。
- 同一题目内容、同一代码和同一困难的已展示上一轮记录才可用于递进；
  客户端 `stage`、`hintLevel`、对话历史不能决定层级。第三级封顶。
- 绑定教师试炼题时检查班级、发布状态；进行中的非自主试炼拒绝此入口。
  该基线没有教师可配置的 `tutoring_policy`，不声称实现全站考试权限封闭。

## 接口与存储

接口均需 JWT，前缀 `/api/v1/agents/tutor-guidance/`：

| 操作 | 内容 |
| --- | --- |
| `POST plan` | 接收当前上下文、可选上一轮编号，返回推荐模式、理由和模式列表；不写提示记录 |
| `POST ask` | 接收 UUID `requestId`、模式、上下文、`previousRequestId`、布尔 `furtherHelp` |
| `POST acknowledge` | 确认本人已展示的 `requestId`；重复确认无额外作用，不代表理解或掌握 |

`tutor_guidance_turns` 保存请求摘要、题目/代码摘要、关注点、模式、阶段、结果及展示标记。
唯一键为账号和请求 UUID。同一编号不同输入拒绝；相同请求返回原结果。
模型调用前持久化请求租约并结束事务；并发重复不另行生成；中断租约60秒到期后可重试。
结果写入校验租约所有权，旧工作不能覆盖重试。当前表无历史清理策略，生产保留期限需另行配置。

迁移：`20261020_0016`，上一个版本 `20260928_0015`。迁移仅新增辅导表。
本仓库现有应用启动也执行 `db.create_all()`；正式部署仍应按既有迁移流程升级。

## 课程证据接入

四模式辅导现通过 `KnowledgeService.retrieve` 按题目、知识点和代码推导出的当前困难检索，
模式分别筛选概念、误区或总结材料。显式模式及提示阶段独立于检索策略，不由旧画像策略覆盖。
当前仅使用课程内已审核且索引就绪的内置教材；本分支尚无上传材料的学生发布权限模型，
因此上传材料不会因“教师审核”标记就自动成为学生可见的辅导来源。

模型接收少量课程片段，需在相关结论后标注 `[S1]` 等本次真实编号。
课程片段中的完整代码块不会传入分模式提示。候选必须有有效引用且通过包含来源支持关系的审核，
否则回退到明确标注的通用编程提示；检索不足、故障及无引用分别记录，不能冒充课程结论。

回答下方增加“课程依据”，展示教材名和章节，点击后核验并展开原文片段。
新增 `POST /api/v1/agents/tutor-guidance/read`（`requestId`）与 `source`（`requestId`、`label`）。
只允许本人读取；来源接口只接受该回答真实引用过的编号，不接受任意文档或片段ID。

所有提供给模型的来源，包括最后没有引用的片段，均保存文档版本和内容摘要。
模型调用结束、缓存重试、展示确认、继续提示、重新打开窗口及展开来源时核验当前可见性。
材料撤回、失去审核状态、版本或正文变化后，旧回答不能继续从服务器返回，前端提示重新提问。
此前已经看过或另存的内容无法撤回。

已在隔离测试中覆盖四模式取材、引用白名单、证据不足、检索故障、材料版本变化与撤回、
跨账号读取和生成期间撤回；并通过真实DeepSeek生成带引用的提示及实际来源展开。
浏览器走查使用真实浮窗组件和已验收回答，验证手机边界、来源核验失败后移除内容。
当前预览向量库仍为内存模式，持久化文件权限问题不属于本次已修复项。
