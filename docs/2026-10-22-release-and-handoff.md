## 维护入口与数据约束

| 模块 | 主要入口 | 维护约束 |
| --- | --- | --- |
| 自主考试、正式作答 | `backend/app/services/student_practice.py` | 判分以服务端执行结果为准，执行服务异常保留待判状态 |
| 隔离判题 | `code_execution.py`、`docker_execution.py`、`deploy/code-sandbox/Dockerfile` | 无网络、只读文件系统、非 root、资源与时间上限；不退回宿主机执行 |

| 小 E 辅导 | `messenger_tutoring.py`、`tutoring.py`、`tutor_policy.py` | 本人上下文、结构约束、语义审核后发布；引用与执行证据分别处理 |
| 试炼统计 | `/api/v1/student/trial-stats/records` | 本人班级试炼、排除内部沙箱；均分不混入自主考试或普通练习 |

## 代码与运行数据的边界

GitHub 为公开仓库，仅同步源码、依赖、模板配置、迁移与可分享文档。`.env`、SMTP 与模型密钥、访问令牌、SQLite 数据库、学习记录、聊天历史、媒体和向量索引不进入提交。

公网更新继续引用服务器原有 `instance` 与 `media` 实际目录，私密配置在服务器内部复制。已有目录可能是软链接；回退目录仍被这些链接引用时不得清理。队友拉取源码后还需自行配置私密环境和运行服务，Git 不会复制个人数据。

## 发布流程与回退

公网入口：<https://106.15.77.40/>。服务为 `plex-backend.service`，Nginx 提供前端及 API 反向代理。

1. 前端执行会话/辅导/用量/反例测试与构建；后端执行回归。按 `.continue/checks/` 核对 Vue 栈、API/JWT、数据库与凭据。
2. 使用 `deploy/build-update-bundle.py --output <新压缩包路径>` 生成仅代码更新包和逐文件 SHA-256 清单；包内不含运行数据。最终包在源码提交后生成。
3. 将包上传到 `/opt/plex-a3/releases/<唯一版本名>/`，核对哈希并解压；执行 `prepare-update.py` 继承配置、链接运行目录、创建私密 SQLite 预演副本。
4. 对副本设置 `DATABASE_URL=sqlite:////.../preflight.db`，运行 `strict-migrate.py <backend目录>`。重复运行确认幂等，确认业务表计数。测试副本之外不得创建演示账号或试卷。
5. 使用服务器实际 Python 环境运行临时数据库六题判分验收及反例执行验收；确认沙箱镜像存在。验证后建立该版本的 `preflight.ok`。
6. 运行 `activate-update.sh <版本名>`：备份前端、停止后端、备份 SQLite、严格迁移、切换后端、等待健康检查、复制新静态资源并最后原子替换 `index.html`。保留旧哈希资源供已打开页面继续使用。
7. 检查 HTTPS、版本、鉴权、新页面与只读接口。将版本名、源码提交、测试结果记录到本文。

激活失败会恢复旧后端代码和前端入口，并重新启动服务。增量 schema 保留；不自动覆盖数据库。手工回退时先停止服务并检查新写入数据，再恢复代码；只有确认需要且经过数据核对后才使用私密 `database-before.db` 备份。不要直接 downgrade 删除新表。
