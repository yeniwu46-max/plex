# PLEX 学生端体验与练习体系升级

日期：2026-10-22。正式实现为 Vue 3 / Naive UI / Flask / SQLAlchemy，保留经典太空与太空漫画两套主题及明暗模式。本轮未提交或推送 GitHub，未覆盖仓库此前的修改。

## 已实现

1. **八步实景导览**：首页、探索舱、学习路径、试炼中枢、资源、小E、画像、设置。先切换路由、等待目标，再显示提示；遮罩透明度 0.35；支持上一步、下一步、关闭、不再提示、加载失败重试。修复 Driver `setSteps` 清空内部 DOM 引用造成跨页残留提示卡的问题。
2. **阅读与资源弹窗**：学生阅读容器隐藏纵向滚动条，继续保留滚动操作；下方有内容时提供可点击的下滑提示。监听器在停用、卸载时清理；减少动态效果时无位移动画。代码和宽表格仍可横向滚动。可学习资源弹窗最大 960px / 94vw，最高 78dvh，中间滚动，8 条分页，桌面双列、手机单列。
3. **真实对战匹配**：无在线同学返回等待态，支持取消和重新匹配；同班、同难度配对；服务端选择双方均可访问的三道题，一并返回题目，不再使用客户端随机补题。线程锁保护当前进程的队列。
4. **自主考试**：随机六道不同编程题，120 分钟；可选最多六个知识点，每点至少一题，剩余尽量均衡分配。题量不足时明确提示，不扩展范围。服务端保存快照、草稿、截止时间；版本冲突返回 409。交卷锁定后异步判题，执行环境不可用时保持待判定并重试。得分为通过题数 / 6 × 100，不额外发放 XP。
5. **教师试卷**：考试区同时展示本班进行中、即将开始的已发布试卷及时间、参与状态，继续走原有教师试炼入口。教师题数、时限和辅导政策不受自主组卷影响。完成试炼的成绩只取服务器正式作答统计，不采用客户端传入的分数。
6. **题库筛选、收藏与正式作答**：服务端完整题库先过滤后分页，支持知识点、难度、关键词、做过/未做过、仅收藏。收藏按账号保存；“做过”指存在正式提交。编程题用隔离执行器判定；普通选择题也补齐服务端提交。教师作答同步写入统一历史，学习事件仍由原链路产生，避免重复计数。
7. **资源回收站**：单条、整包删除及按条、按批次恢复。七天严格为服务端删除时刻起 168 小时。整包删除不刷新此前删除条目的到期时间；批次恢复不恢复其他批次。列表、详情、任务结果与下载检查删除状态，资源包内容剔除已删除子项。到期禁止恢复，后台清除正文、保留墓碑与审核证据。
8. **小E两模式**：顶部“随心问 / 关联题目”，右上角 BOX 菜单保留创建、切换和重命名。练习工作区可携带当前代码进入关联模式，也可选择本人正式作答；卡片可展开代码附件。服务器验证记录归属、版本和考试限制。完整正文、代码、引用、流式输出、取消和重试沿用原链路。
9. **探索地图画像**：复用八大学域知识图谱，提供搜索、缩放、定位、键盘知识点列表。详情显示独立/辅助作答、误概念和复习安排；无正式证据显示“待了解”。桌面详情面板、移动端底部抽屉。自述资料与校准放在资料抽屉，历史按需展开；资料完整度不再与掌握度混为一谈。

## 数据与迁移

迁移：`backend/migrations/versions/20261022_0035_student_practice.py`，前置版本 `20261018_0034`。

- `student_practice_attempts`：本人、规范题目标识、版本、代码、正式结果、来源、时间。UUID 用于幂等；考试每题使用确定性 UUID，重试不重复计分。

- `student_mock_exams`：题目快照、答案、判定结果、修订号、时限及判定租约。唯一的活动账号槽避免同账号同时创建两份试卷。
- `personalized_learning_resources`：新增 `deleted_at`、`expires_at`、`deletion_batch`、`purged_at`。

本机 MySQL 已从 0034 升至 0035。SQLite 已验证重复升级与降级往返保留既有资源行。新环境须先备份数据库，按现有部署迁移流程升级至 head 后再运行服务。不要用清库/重新初始化替代迁移。

不按旧系统编号猜测历史记录归属，不伪造历史题目版本；新的完整作答历史从升级后开始积累，原有教师作答和学习证据继续保留。

## 接口契约

下表统一前缀 `/api/v1/student`，要求学生 JWT；所有新写入和本人历史均按 JWT 用户验证，不接收客户端指定所有者。返回沿用 `{code,message,data}`。

| 方法与路径 | 参数 / 行为 |
|---|---|
| GET `/practice-questions` | `knowledge_key,q,difficulty,done=yes/no,favorite=true,page,page_size`；返回 `items,total,page,page_size`，每项含 `favorite,done,canonical_ref` |
| PUT / DELETE `/question-favorites/<ref>` | 收藏 / 取消收藏 |
| POST `/practice-submissions/<ref>` | `request_id` UUID、`code`、可选 `question_version`；选择题传 `selected_index`。重用同 ID 但不同答案返回 409 |
| GET `/practice-history` | `page`，可选 `question_ref`；每页 20 条，最新优先 |
| GET `/practice-history/<id>` | 只返回本人的一条正式作答；其他用户返回 404 |
| GET / POST `/mock-exams` | 查询最近考试 / 创建考试；创建传 `{knowledge_keys:[]}`，省略或空数组为全部可访问编程题 |
| GET `/mock-exams/<id>` | 包含 `server_time,deadline,revision,status,questions,answers,score`；到期锁定；考试中不返回隐藏测试和答案 |
| PATCH `/mock-exams/<id>/answers` | `{revision,answers:{题号:代码}}`；返回新 revision，冲突/截止返回 409 |
| POST `/mock-exams/<id>/submit` | 幂等锁定；返回 pending/grading/completed 状态，后台评分 |
| GET `/personalized-resources/<id>` | 当前可访问资源详情；下载前再次读取，已删除/失效返回 404 |
| DELETE `/personalized-resources/<id>` | 单条移入回收站，返回 `batch_id,count` |
| DELETE `/resource-packages/<task_id>` | 只删除当时正常的包成员；生成中返回 409 |
| GET `/resource-trash` | `page`；20 条/页，返回删除与到期 UTC 时间、批次及总数 |
| POST `/resource-trash/restore` | `{resource_id}` 或 `{batch_id}` 二选一；只恢复本人未到期成员 |

现有辅导上下文接口增加 `submission_id`。服务器绑定题目和版本，不信任浏览器传入的判题结论；当前题目在本人未交卷考试中时禁用关联辅导。自由聊天仍是一般性聊天，不宣称能阻止学生向外部工具提问。

## 运行与维护

- 前端 `http://127.0.0.1:5180`；后端 `http://127.0.0.1:5100`，前端代理 `/api`。
- 代码判题依赖隔离执行器。本机 Docker Desktop 已启动，镜像 `plex-python-sandbox:1` 可用；不会降级到宿主机直接运行学生代码。
- 应用默认启动维护线程，每 15 秒做有界到期检查及待判题处理。测试环境关闭线程。也可由调度器在 `backend/` 执行 `python manage.py student-maintenance`。
- 资源文件采取保守保留：到期正文清空，墓碑/审计和媒体路径关联保留；仅被删除资源引用的媒体 URL 返回 410。**本次没有物理删除磁盘媒体文件**，以免误删教师原件或共享引用；后续独立文件 GC 应先建立全量引用索引。
- 对战队列仍为单进程内存状态；重启会清空。多进程/多实例部署前需迁移到共享队列，不能将当前实现描述为跨节点匹配。
