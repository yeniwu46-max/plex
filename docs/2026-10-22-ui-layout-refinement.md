# PLEX 三端顶部与学生端布局修正

日期：2026-10-22。正式前端为 Vue 3 / Naive UI，后端为 Flask。实现阶段保留原工作区改动，未自动推送 GitHub；此 UI 修正本身不新增数据库表或迁移。后续已按用户要求发布，见 [当日发布交接](2026-10-22-release-and-handoff.md)。

## 实现范围

- 三端公共顶栏删除可见的重复页面标题、副标题，保留屏幕阅读器标题、搜索、通知、外观和头像操作。管理员独立顶栏同步收紧。
- 学生八步导览改用真实功能锚点：今日学习概览、班级试炼入口、路径操作、题库筛选、资源生成、聊天模式、画像地图、外观设置。跨路由等待目标出现，自动滚入视野；滚动和缩放更新高亮位置，支持前后、关闭、重试和跳过。
- 阅读区域隐藏原生纵向滚动条，主题化“继续浏览”提示跟随实际滚动容器。打开弹窗后只处理顶层弹窗，避免背景箭头穿透；到末尾隐藏。代码和宽表格保留细滚动条。资源正文取消嵌套的第二层纵向滚动。
- 小 E 顶栏采用正常文档布局：左侧“随心问 / 关联题目”，右侧“查看用量 / BOX”。用量放入不超过 460px 的弹窗；BOX 保留会话功能。重新分配对话和输入区高度，消除窄屏重叠。
- 自主组卷的选择框和按钮横向排列，按钮自然宽度、最多 220px；手机换行靠右。六题、120 分钟等业务规则未改。
- 试炼页使用紧凑的四项指标和“战绩记录 / 反例挑战”入口。指标可打开本人分页明细；不再用最近八条记录计算总数或均分。收藏统一图标、选中状态和独立点击区域。
- “回收站”常驻个性化资源页“我的资源”工具栏右侧；删除提示可直接打开回收站。保留原七天恢复规则。
- 经典 / 漫画主题各自沿用其颜色、边框和阴影，适配深浅色；减少动态效果设置下关闭提示位移和导览动画。

## 战绩接口

`GET /api/v1/student/trial-stats/records`

JWT + student 角色；用户身份只来自服务端 JWT。客户端不能指定他人账号。与既有 `GET /api/v1/student/trial-stats` 使用同一可见性函数。

| 参数 | 默认值 | 约束 |
| --- | --- | --- |
| status | all | all / completed / active |
| page | 1 | 正整数 |
| page_size | 10 | 1–50 |

响应沿用 `{code,message,data}` 包装；`data` 为：

```json
{
  "items": [{
    "id": 12,
    "trial_id": 8,
    "title": "循环边界练习",
    "status": "completed",
    "score": 100,
    "joined_at": "2026-10-22T01:00:00",
    "completed_at": "2026-10-22T02:00:00"
  }],
  "total": 1,
  "page": 1,
  "page_size": 10
}
```

以上只是字段示例，不是新增业务数据。

- 统计来源仅为本人班级试炼参与记录，排除内部沙箱；不合并普通练习或自主考试。
- `active` 筛选数据库 `joined` 状态；明细状态保留 `joined/completed/abandoned`。
- 按参与时间倒序、记录 ID 倒序稳定排序。越界页返回空列表。
- 非完成记录 `score=null`；不返回参考答案、题目内容或其他学生信息。
- 四项汇总均为全量本人记录；均分沿用服务端全部已完成成绩的算术平均及 `round` 整数口径。无已完成记录时前端显示“暂无”。
- 非法参数返回 HTTP 400 / code 40001，未登录 401，非学生 403。
- 当前数据量下复用既有全量统计查询，在服务端过滤并分页切片；大规模使用前可进一步优化为 SQL 聚合与分页，保持相同过滤口径。

## 浏览器验收

使用本机 Chrome 和已有演示账号，前端 5180、后端 5100。未创建真实考试或提交模型请求；本轮收藏测试已恢复原状态，未删除或恢复用户资源。

- 八步导览逐项进入正确路由与锚点；上一步正常，每步仅一个气泡；结束后遮罩和气泡均清除。试炼步骤从桌面缩到 390px 后正常重定位。
- 小 E 的四套外观组合、1440/1024/768/390px 布局进行浏览器检查；用量弹窗、BOX、模式切换可操作。
- 试炼完成数 2、进行中 1、累计参与 3、均分 100 与本人明细一致；“战绩记录”包含原两条 100 分记录。收藏添加、筛选、取消均可用。
- 390px 下组卷按钮实测宽约 140px，没有形成满行长条。
- 回收站入口与弹窗可打开，显示既有资源保留时间及恢复入口。
- 390px 下可学习资源弹窗宽约 366.6px，手机单列，无页面横向溢出；正文实际容器隐藏原生条，End 键到末尾后提示消失。资源讲解弹窗复查后只剩一个主要纵向阅读区，背景箭头不穿透。
- 学生与教师重复标题隐藏且功能分区标题保留；教师头像菜单在新验收标签页正常展开并可退出登录。
- 管理员已登录实测，重复标题为 1×1px 的屏幕阅读器文本，控制台指标与功能区保持显示；关闭首次导览后头像菜单正常展开，退出登录正常。

## 验收边界

未在浏览器人为注入断网、服务端错误或导览目标加载超时；相应重试 UI 已实现，但不将源码检查记为实测通过。未切换操作系统“减少动态效果”偏好做实机检查；相关 CSS/JS 分支已保留。响应式检查以桌面 Chrome 视口模拟为准，不能替代真实 iOS/Android 设备测试。浏览器部分标签页曾出现自动化响应停滞，新标签页能正常操作；不将该情况归为已确认的产品缺陷。
