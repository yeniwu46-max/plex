# PLEX 深色太空漫画 UI 改版提示词包

日期：2026-10-12。适用于 PLEX 学生端局部视觉改版，已完成效果图确认与 Vue 页面实现。

本文件包含可直接交给开发助手的总提示词、四张效果图的原始生成提示词、实施定位和验收要求。效果图负责确定视觉方向，实际页面使用真实组件和业务数据。

## 1. 使用方式

- 修改页面：复制第 2 节的完整提示词，并提供当前仓库。
- 生成效果图：使用第 4 节对应区域的提示词，附上相应原始截图；不要只提供文件名。
- 在当前版本上继续调整：结合第 3 节的源码位置，优先复用现有组件和配色变量。
- 四张已确认效果图、原始截图和实际页面截图见 [设计归档](design/plex-comic-2026-10-12/README.md)。

## 2. 可直接复制的页面实施总提示词

```text
请对 PLEX 学生端的四处现有 UI 实施“深色太空漫画风”改版：新手导航、探索舱资源看板、小E聊天页、顶部信息栏。先阅读仓库说明和相关组件，确认正式前端为 Vue 3 + Vite + Naive UI + Pinia + Axios，后端为 Flask。沿用现有框架、组件、路由、状态和接口，不另做 React 原型。

工作顺序：
1. 如果尚未确认视觉，先生成四张独立效果图：导航、资源看板、聊天、顶部信息栏；聊天图同时展示空态和消息态。提供给用户审阅，确认后再落代码。
2. 如果用户已批准效果图，直接实施，不重复要求确认。当前这版已经获得用户“按这版落地”的批准。
3. 完成后运行现有构建检查，实际操作浏览器，输出页面截图与准确的验收结果。

统一视觉：
- 保留原有星空背景、青色品牌和小E机器人身份。
- 深蓝底 #07131F，面板蓝 #11263A，青色 #55EEE9，辅助黄 #F6CD68，正文白 #EEF7FF。
- 用约 2px 描边、3–5px 硬阴影、分镜边框、徽章、少量倾斜贴纸和带尾角的对话框制造漫画感。
- 网点仅放在空白角落，不覆盖正文。保持充足留白，避免满屏颗粒、强烈霓虹和模糊光效。
- 中文继续用清晰现代黑体。正文、按钮文字和代码保持平直、单层锐利，不描边、不发光、不使用文字阴影。
- 小E为白色圆头盔、深色面罩、青色眼睛的机器人，可使用可缩放的原生 SVG。小图标、头像和欢迎形象保持一致。
- 效果图只作为设计依据，不能把整张效果图铺成页面来代替真实控件。

区域一：新手导航
- 把弹窗做成“小E导航气泡”。标题、黄色步骤徽标、说明文字、操作按钮形成清晰层级。
- 保留关闭、上一步、下一步、完成、不再提示以及菜单重新开启导览的现有逻辑。
- 首步“上一步”仍禁用，主按钮青底深字。
- 已知重影原因是 Driver.js 默认按钮 text-shadow: 1px 1px 0 #fff；需要明确设置 text-shadow: none，并覆盖正常、悬停、禁用状态。
- 文字阴影修复覆盖学生、教师、管理员三种角色；漫画弹窗外观限定学生端。
- 给键盘 focus-visible 提供清晰描边。弹窗和箭头适配深浅主题及手机宽度，不遮住关闭按钮。

区域二：探索舱资源看板
- 做成横向漫画分镜：左侧 Explorer 身份和等级徽章，中部为分段 XP 条，右侧为三格资源统计。
- 保留真实姓名、等级、经验、连续探索、待完成任务和“更多”入口，不写死演示数值。
- 设计预览沿用截图中的 Explorer · 学生1、Lv.10、24000 / 24000 XP、累计 XP 24000、待完成任务 0、连续探索 30 天。
- XP、任务、探索分别用青色 XP、黄色拼图和青色星星图标区分。
- 桌面横向排列，平板可上下堆叠，手机保持三格资源清楚可读。长姓名、长数字不能撑宽页面。

区域三：小E聊天页
- 保留“小E 对话反馈”、会话选择、创建和最近使用时间。
- 空态放置小E形象和欢迎气泡，文案为“向小E提一个 Python 或学习问题”“探索之路固然艰难，有什么疑惑我帮你解决！”。
- 消息态：用户气泡靠右、青底深字；小E气泡靠左、深蓝面板，配头像与气泡尾角。
- 会话切换做成页签式控件；保留已有创建、切换、重命名和会话数量限制。
- 保留输入框、更多工具、语音、发送，以及“诊断薄弱点”“推荐下一试炼”“规划修复路线”“查看最近成长”四个快捷入口。
- 保留 Markdown、代码高亮、代码块横向滚动、图表、知识引用、来源查看、下载和流式状态等已有能力。
- 不改变消息内容与发送链路。请求中按钮禁用状态仍明确可见，不把模拟消息当作模型成功证据。
- 长文本自动换行；代码和表格在自身容器内滚动，不撑破气泡或整页。小屏输入区允许换行，四个快捷操作可以排成两列。

区域四：顶部信息栏
- 通知与主题切换使用独立方形圆角描边按钮，保留原有功能。
- 通知数量做成红色角标贴纸，显示真实未读数量。
- 小E头像、真实姓名与黄色等级徽章组成紧凑身份卡，保留下拉菜单和菜单操作。
- 通知弹层、用户菜单沿用同一套配色和边框。窄屏不能挤出页面，角标和阴影不能被裁掉。
- 学生端使用漫画风；教师、管理员的顶部栏继续保留各自既有视觉。

工程边界：
- 不修改 API、数据库、认证或业务字段，不新增不存在的统计和功能。
- 使用明确的学生区域类名限制样式作用域，避免覆盖教师端、管理员端及无关页面。
- 检查原有 scoped 样式、Naive UI 变量和浅色主题 !important 规则，确保实际计算样式符合设计。
- 浅色模式同步保证标题、正文、占位文字、引用卡片和按钮的对比度。
- 不覆盖工作区已有的无关改动，不把本地密钥、数据库、缓存和运行日志当成交付文件。

验收：
- 执行现有 npm run build，包括项目配置的文案检查、Vue 类型检查、Vite 构建与包体预算检查。
- 检查三角色深浅主题下导览正常、悬停、禁用和键盘焦点状态，确认文字无重影。
- 操作关闭、前进、后退、完成和重新开启导览。
- 检查 1440、1024、768、390px 宽度及浏览器缩放，观察页面是否横向溢出、遮挡或裁切。
- 操作通知、主题、个人菜单、会话切换与发送；验证空态、真实消息、流式中间态、长代码和引用卡片。
- 采用实际浏览器截图和交互验收，不新增只复述 CSS 属性的单元测试。
- 明确区分“已验证”“仅代码支持”“尚未验证”；未执行的测试和后端异常如实记录，不编造成功率或性能指标。
```
