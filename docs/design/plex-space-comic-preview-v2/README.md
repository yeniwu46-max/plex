# PLEX 五区域太空漫画效果预览

制作日期：2026-10-13。用途：视觉审阅与轻互动体验。

## 打开预览

- 当前本地入口：[http://127.0.0.1:5188/](http://127.0.0.1:5188/)。
- 本目录的 `index.html` 是独立预览入口。默认进入“交互预览”，顶部可切换到“五张效果图”。
- 若本地服务已停止，在本目录执行 `python -m http.server 5188 --bind 127.0.0.1`，再打开上述地址。

## 交互说明

- 可操作按钮和卡片支持约 180ms 的轻微悬停、按压反馈。
- 首页仪表附近的小星星在鼠标进入或键盘焦点进入时闪亮一次。
- 两个下拉框可以展开、选择当前项、用 Esc 关闭；点击外部也会关闭，同一时刻只展开一个。
- 本次只有截图中的当前选项，不新增知识点和资源类型。
- 静态战绩和“最新任务”保持静态。所有统计均固定为用户截图中的值。
- 按钮不会进入正式系统、创建任务、调用模型或模拟生成成功。页面使用 `connect-src 'none'` 禁止请求业务接口。
- 为键盘用户提供黄色焦点轮廓；CSS 包含 `prefers-reduced-motion` 降级，取消位移、闪亮和过渡。

## 素材与复用

- `preview.css`：独立视觉样式、四档响应式布局与轻动效。
- `preview.js`：模式切换、下拉框和局部视觉反馈。
- `assets/xiao-e-wave.png`：从首页效果图衍生的透明背景小 E 插画，使用内置图像工具生成。
- `assets/corner-dots.svg`：原生矢量网点装饰；图标直接定义在 HTML 内。
- `prompts.json`：五张效果图的完整提示词和原始参考图路径。
- `mascot-prompt.txt`：透明小 E 插画的完整生成提示词。
- `verification/`：浏览器验收截图与检查记录。

本目录归档的是 2026-10-13 的独立视觉预览。之后正式 Vue 页面已完成双主题实现，见 [双主题说明](../../2026-10-13-student-visual-themes.md)。此独立预览页仍使用截图固定值，不连接业务 API。

## 验证口径

- 已在实际浏览器检查 1440、1024、768、390px 宽度，正文和控件没有横向溢出；图片加载正常。
- 检查了下拉展开/关闭、键盘 Enter/Esc/Tab、可见焦点、按钮悬停反馈、五图与交互预览切换。
- 标题、按钮和统计数值的计算样式均为 `text-shadow: none`。
- 预览脚本通过 `node --check`。正式应用未改动，未重复运行正式前端构建。
- 减少动态效果的媒体规则经过代码与浏览器 CSSOM 检查；本轮浏览器工具没有提供系统动态偏好的切换能力，因此没有声称完成该偏好的运行态切换测试。
