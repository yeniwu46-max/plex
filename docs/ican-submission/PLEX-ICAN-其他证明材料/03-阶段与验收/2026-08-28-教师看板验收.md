# 教师风险看板浏览器验收清单

## 验收目标

在教师账号、选定班级和同一统计周期下，能够从看板定位风险学生，看到可解释因子，查看知识薄弱点，并进入干预工单闭环。此清单只规定验收步骤，不把本地演示数据写成真实教学效果。

## 操作与证据

1. 登录教师账号，选择目标班级，记录班级名称、统计周期和页面时间。
2. 截图或录屏顶部指标：学生数、活跃人数、需跟进学生数、今日修复率。
3. 打开“需要关注的 Explorer”，记录至少一名学生的风险等级和风险原因；同时保留“主要风险因子”摘要。
4. 查看“班级知识域掌握度”和“错题类型分布”，确认图表与当前班级一致。
5. 点击风险学生进入学生详情，记录风险标签、学习指数、趋势和证据条目；不得展示姓名、手机号等不必要敏感信息。
6. 打开干预工单，完成 `open → in_progress → resolved` 状态流转，记录操作者角色、时间、备注和关联知识点。
7. 刷新页面，确认工单状态、风险原因和学生摘要仍然可见，形成前后截图对照。

## 通过条件

- 风险等级、主要因子、知识薄弱点和趋势均可定位到同一学生/班级。
- 贡献因子带 evidence；页面不宣称这些确定性贡献就是 SHAP。
- 工单状态流转可持久化，越权角色不能修改工单。
- 截图或录像包含页面时间、班级、统计周期和脱敏账号标识。
