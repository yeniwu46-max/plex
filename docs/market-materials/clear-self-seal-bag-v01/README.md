# 小 E 透明自粘包装袋 v01

本版用于单张 55×85 mm 收藏卡，延续已确认卡面的薄荷青、浅天蓝、奶油白与简洁漫画轮廓。袋子大部分保持透明，只在下沿放小 E 半身像、细星轨和四角星；无字、无二维码、不加满版底色。

## 文件

- `xiao-e-bag-mockup.png`：左侧空袋、右侧装卡效果图，展示透明度和装饰位置。仅为产品外观示意，不作为精确尺寸模板或直接印刷稿。
- `xiao-e-clear-label-60x20mm.png`：真正透明底的独立图案，供商家排版到透明贴纸。2172×724 px，RGBA；按 60×20 mm 放置约 919 ppi，背景约 87.8% 像素完全透明。头盔、星标内部的奶油白是图案颜色，应保留。
- `generation-prompts.md`：内置 image_gen 完整提示词及参考文件。

## 暂定结构尺寸

| 项目 | 设计基准 |
| --- | --- |
| 使用场景 | 一张 55×85 mm、直角收藏卡；不是手办袋或 A6 贴纸套装袋 |
| 袋身 | 70×110 mm，竖版 |
| 折口 | 另加约 30 mm，自粘封口折到背面 |
| 袋子外观 | 高透明、无色、不磨砂、无拉链、无挂孔 |
| 装饰贴纸 | 60×20 mm，矩形透明底，不做复杂异形刀模 |
| 贴纸位置 | 正面下沿，左右各约 5 mm，下边离袋底约 3 mm |
| 背面及折口 | 不印图案，保持透明 |

以上为本次设计假设，尚未拿到商家袋型模板。采购时确认尺寸是内径还是外径、是否另计折口，确认实际可用空间能装入收藏卡。袋子侧边热封和制造公差会占空间。不要把“袋身 110 mm”误当作“含折口总长 110 mm”。

## 制作方式

建议此次先询价“现成透明 OPP 自粘袋 + 一张透明不干胶贴纸”，按 100 套核算袋子、贴纸、白墨、运费的合计。图案集中成一条，便于贴在袋子下沿；整袋直接印刷也能采用相同设计，但应另核对起订量、制版费用和交期。当前未获得报价，不声称任何方案的实际价格或到货时间。

透明贴纸只在图案形状下方做局部白墨，保留透明背景；特别是小 E 的白色头盔、手套和四角星中心，不能把它们当作镂空区域。白墨也不要铺成整张白色矩形。透明贴纸在图案背后印白墨以保持不透明度，是已有印刷商使用的工艺：[Sticker Mule 白墨说明](https://www.stickermule.com/faqs/stickermule/are-you-able-to-print-white-ink-on-clear-stickers)。

自粘折口和透明聚丙烯袋结构可参考 [Associated Plastics 产品说明](https://www.associatedplastics.com.au/products/polypropylene-resealable-bags)。该链接只用于结构参考，不代表本设计的 70×110 mm 已有货，也不是购买建议或本地报价。

PNG 没有单独的白墨专色通道、刀模线或商家出血模板。商家需按最终尺寸排版、处理白墨和裁切；这是可继续制版的彩色透明底设计原稿，不冒充已完成印前分色的生产文件。请用 PNG 原图，不要用带灰色背景和塑料反光的效果图印刷。
