# PLEX 作品展板 v01

主题：**把编程，学成一场宇宙探索。**

为线下集市制作的 80×180 cm 竖版 X 展架。奶油白、浅天蓝和薄荷青构成清新的漫画探索旅程；五张小 E 插画、四段体验流程、技术反馈图和独立扫码票根共同组成完整画面。

## 发给制作商的规格

- 成品：**800×1800 mm**，竖向 X 展架画面，整幅按 **100% 实际尺寸** 输出，不使用“适合纸张”。
- PDF 页面 / 出血范围：**810×1810 mm**。四边各 5 mm 出血，TrimBox 明确标出 800×1800 mm 成品框。裁切线不印入画面。
- 重要内容距成品边缘至少 35 mm。尚未加入特定展架的孔位；请以商家提供的模板复核四角孔位和出血要求后制作，不要直接给图案打孔。
- RGB 原稿，未指定 ICC 配置。由印厂按实际材料、设备和色彩流程转换；如需 CMYK，应使用印厂指定配置，避免反复转换。
- 五张插画按实际放置尺寸约 **151.7–162.1 ppi**，未靠放大像素冒充清晰度。PDF 中字体、流程图和二维码为矢量。
- 字体：中文 Noto Sans SC（正文 400、标题 800），PLEX 字标 Bahnschrift。PDF 已嵌入字体子集。
- SVG 内嵌 WOFF2 字体子集；个别桌面编辑器可能忽略 SVG 内嵌字体，编辑时请安装 Noto Sans SC 并保留对应字重，Bahnschrift 使用 Windows 本机字体。印刷请优先使用已校验 PDF，避免未经检查重新导出。
- 最下沿仅有背景线条，收尾与署名位于安全区。

## 设计与技术表达

- 内容顺序：先认识你 → 找到你的学习航线 → 卡住了，也有人陪你闯 → 让每一步成长看得见。
- 技术图展示学习画像、知识检索、多智能体协同、学习支持和反馈回路；教师侧连接协同资源环节与学习支持。
- 图示表示能力与数据关系，不表示每次请求都会启动全部智能体。
- 学校仅以“江南大学”文字署名；未加入提分率、规模、获奖或其他未经证实的宣传数据。
- 插画参考：`../explorer-card-v02/xiao-e-explorer-front.png`。工具：内置图像生成。生成时间：2026-10-12。没有把中文交给图像工具生成。

## 复现

在已安装 `reportlab`、`pypdf`、`Pillow`、`qrcode`、`fonttools`、`brotli`、`zxing-cpp` 的 Python 环境运行 `build_board.py`；首次构建读取本机 Noto Sans SC 与 Bahnschrift 字体。脚本以本目录素材为准，不需要重新生成插画。

预览通过 Poppler 从最终印刷 PDF 渲染：50.8 dpi，对含出血页从 `(10, 10)` 像素处取 `1600×3600` 像素的成品范围。之后运行 `verify_board.py` 检查尺寸、中文、嵌入字体、矢量内容、分辨率、安全边距与 QR 解码。
