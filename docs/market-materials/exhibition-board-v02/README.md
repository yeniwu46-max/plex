# PLEX 作品展板 v02：大字与饱满布局版

这一版按反馈放大文字、增加功能信息、减少空白。上一版保留在相邻的 `exhibition-board-v01/` 目录，方便比较。

## 主要调整

- 主标题改为三行，字号从 126–136 pt 提高至 **170 pt**；PLEX 字标由 176 pt 提高至 **215 pt**。
- 分镜标题由 53–56 pt 提高至 **72–82 pt**；正文由 32 pt 提高至 **44 pt**，增加 37.5%，以短句分行排版。
- 新增四条功能标签：基础 / 目标 / 节奏、知识星轨 / 下一步推荐、探索舱 / 小 E 陪伴、错题复习 / 成长档案。
- 技术区增加五个环节的短解释：诊断看基础、检索找依据、资源配内容、路径排顺序、反馈再调整。
- 强化斜切色块、大编号和标题反白色条；保留清新的浅蓝、薄荷青和奶油黄。
- 五张插画沿用上一版原始素材，排版放大后仍达到至少 150 ppi。所有文字、技术图和二维码保持矢量。

## 印刷规格

- 成品 **800×1800 mm**，竖版 X 展架。
- 四边各 **5 mm 出血**；PDF 页面 810×1810 mm，TrimBox 标出成品框。
- 按 **100% 实际尺寸** 制作，不使用“适合纸张”。预览 PNG 不作为印刷母版。
- 重要内容距成品边缘至少 35 mm；仍需制作商根据展架孔位模板复核。
- RGB 原稿。由印厂按照具体材料和设备转换，未擅自指定 ICC 配置。
- Noto Sans SC（正文 400、标题 800）、Bahnschrift 字标；PDF 嵌入子集字体。
- SVG 内嵌字体可能被部分桌面编辑器忽略，编辑时安装对应字体并核对字重；直接印刷优先采用已校验 PDF。
- 插画实际有效分辨率最低约 **150.2 ppi**，未经插值放大像素。

## 复现

在具备 `reportlab`、`pypdf`、`Pillow`、`qrcode`、`fonttools`、`brotli`、`zxing-cpp` 的 Python 环境运行 `build_board.py`；首次构建读取 Windows 字体目录中的 Noto Sans SC 和 Bahnschrift。已有素材从本目录直接读取。

随后用 Poppler 将 PDF 按 50.8 dpi 渲染，从含出血页的 `(10,10)` 像素位置截取 `1600×3600` 成品区域，再运行 `verify_board.py`。`layout_definition.py` 是主布局的独立副本；最终复现以完整 `build_board.py` 为准。
