# 小 E 探索者收藏卡 v02 · 清新配色

本版按用户反馈改用奶油白、浅天蓝、薄荷青，辅以少量奶油黄和浅桃色；去掉密集的黑色颗粒、碎屑与强烈撞色射线，仅保留两处浅色漫画网点和疏朗星轨。小 E 的图形眼睛、头盔、耳部、披风及四角星保留，双面均无文字。

## 交付文件

- `xiao-e-explorer-front.png`：正面 RGB 原图，小 E 向观者跃出。
- `xiao-e-explorer-back.png`：反面 RGB 原图，小 E 面向四角星门户。
- `xiao-e-explorer-card-print-61x91mm.pdf`：两页实际尺寸印刷稿，第 1 页正面，第 2 页反面，均朝上。
- `generation-prompts.md`：内置 image_gen 的完整提示词、参考图及生成记录。

## 印刷规格

| 项目 | 规格 |
| --- | --- |
| 成品 | 55×85 mm，竖版、直角裁切 |
| 含出血原稿 | 61×91 mm，四边各 3 mm 出血 |
| 角色安全距离 | 裁切线内至少 3 mm，即含出血画幅边缘内 6 mm |
| 材质 | 300g 铜版纸、双面覆哑膜 |
| 原图 | 每面 1027×1532 px，RGB，不含透明遮罩 |
| 有效分辨率 | 横向 427.64 ppi、纵向 427.61 ppi，按 61×91 mm 放置 |
| PDF 页面 | MediaBox / CropBox / BleedBox 为 61×91 mm |
| PDF 裁切框 | TrimBox：左下角 (3,3) mm 至右上角 (58,88) mm，55×85 mm |

请优先使用 PDF 排版。PNG 保持生成工具原始像素，没有固定物理尺寸元数据；使用 PNG 时须把整幅设置为 61×91 mm，再裁去四边各 3 mm，不能直接把含出血画幅缩成 55×85 mm。PDF 按实际物理尺寸放置，没有降采样或改动原图像素。

文件保留 RGB；没有商家 ICC 配置时，不自行指定 CMYK 转换。请印厂按其设备及纸张流程转换并确认样张。PDF 内不画裁切线，由印厂按 TrimBox 拼版。两页上下朝向一致；桌面打样选择实际大小 / 100%、长边翻转。印厂自行处理双面拼版对位，最终两面应均朝上。

100 张约 30 元仍只是询价目标，实际价格、工艺、运费和时效由商家确认。尚无商家专用模板，收到后需再次核对出血和裁切位置。
