# 项目需求分析说明

PLEX 面向 Python 程序设计初学者，解决统一教学内容难以适配不同基础、目标、
表达偏好和学习节奏的问题。核心用户为学生、教师和管理员。

核心需求包括：学生通过自然语言构建不少于七维的动态画像；多智能体读取画像和
课程知识库，一次生成讲解文档、思维导图、分层练习、拓展阅读和代码实操五类资源；
系统根据作答、错题和画像变化调整学习路径与推荐；教师审核低置信度资源并查看干预
依据；管理员观察任务后端、成功率、风险和降级状态。

非功能要求包括 JWT 权限隔离、课程范围限制、提示注入防护、引用校验、上传安全、
任务幂等和恢复、SQLite/MySQL 可移植性以及离线降级演示。

当前核心闭环为本地验收状态。真实讯飞 Spark、在线 GitHub CI 和 MySQL 8 运行结果
属于外部阻塞项，不能用本地规则或 Mock 冒充。
