# 系统设计与开发说明

系统采用 Vue 3、Vite、Naive UI、Pinia 和 Axios 构建前端，Flask、
Flask-SQLAlchemy 与 JWT 构建 REST 后端。生产数据库目标为 MySQL 8，本地允许
SQLite。接口统一使用 `/api/v1` 前缀和结构化 JSON 响应。

业务分为画像、资源生成、试炼作答、错题、推荐、学习路径、知识库、教师审核和
系统观测模块。资源任务保存画像版本、知识点、请求类型、实际后端、任务步骤、
引用、置信度和审核状态。学生只能访问本人数据，教师只能访问所管理班级，管理员
承担系统配置和观测职责。

系统设计重点是同一事实源：学生成长档案和教师学生档案调用同一学习效果服务；
推荐与星轨共享画像和薄弱点排序；待审核资源在批准前不向学生发布。

本地入口为根目录 `start.bat`。`start.bat --check` 只执行环境、迁移、种子数据、
健康和演示账号检查，不启动服务。
