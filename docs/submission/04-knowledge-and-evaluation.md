# 课程知识库与评测数据说明

课程范围固定为 Python 程序设计基础，覆盖 16 个知识点。每个知识点拥有唯一
`document_id`、明确章节、概念、正反例、常见错误、基础练习、进阶练习和来源。
`python manage.py knowledge-check` 与 `verify_knowledge_base.py` 检查缺失文件、
空章节、重复或孤立 ID 以及无效映射。

个性化评测使用两组固定画像，覆盖全部 16 个知识点和五类资源，统计任务成功率、
Schema 通过率、引用有效率、画像约束覆盖率、资源差异度、延迟和降级率。画像抽取
评测覆盖完整、单字段、模糊、冲突和未提及表达。

学习效果报告以资源生成时间为介入点，比较同一知识点前后至少三次有效作答。样本
不足时返回 `insufficient_evidence`，变化量为空，不制造提升结论。

当前知识库、个性化和学习效果为本地确定性验收。真实模型与本地规则的质量和延迟
对比仍依赖讯飞凭证。
