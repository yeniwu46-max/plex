# 创新点与应用价值说明

PLEX 的差异不是增加一个通用聊天框，而是把画像、资源、路径、作答、反馈和教师
审核组成可审计闭环。

第一，七维动态画像同时保存字段来源、置信度和版本，支持学生确认与行为建议。
第二，六角色资源工厂保存每一步结构化产物和实际后端，使“多智能体”可追踪而不是
进度动画。第三，五类资源对同一知识点产生可量化的难度、表达、案例和练习差异。
第四，低置信度、引用异常和安全风险进入教师审核，形成教育场景的人机协同质量控制。
第五，学习效果以数据库作答记录和明确介入点计算，证据不足时拒绝输出提升结论。

系统同时提供离线规则降级、任务幂等、失败恢复和三角色权限隔离，适合网络条件不稳
的课堂和比赛现场。后续真实讯飞验收将补充模型质量与延迟证据，但不会改变本地结果
的真实状态标识。
