# 七分钟演示脚本

## 主路线

- `0:00-0:35`：说明统一内容难以适配不同学习者，以及 PLEX 的闭环方案。
- `0:35-1:20`：学生通过对话建立七维画像，展示来源、置信度和版本。
- `1:20-2:20`：选择 `loop` 生成五类资源，展示六个智能体步骤和实际后端。
- `2:20-3:10`：打开资源，展示难度、案例、引用、置信度与推荐理由。
- `3:10-4:00`：在星轨查看路径，侧栏展示「学习路径智能体」时间线（前置、掌握度、难度、推荐资源）；切换知识星图可见路径高亮与补救标记；完成循环边界错误并形成错题。
- `4:00-4:50`：接受画像建议，展示版本、路径和推荐排序变化。
- `4:50-5:40`：成长档案展示前后测；证据不足场景明确显示不可计算。
- `5:40-6:25`：教师查看同一事实源，填写审核说明并批准或驳回资源。
- `6:25-7:00`：管理员展示健康、实际后端、安全和性能报告，说明外部阻塞。

## 备用路线

无外网时使用 `local_rules` 和已批准演示资源，页面保持实际后端标识。不得切换数据库
或手工伪造任务状态。若现场生成失败，展示可恢复失败与重试，再使用预生成且已审核
的同画像资源完成闭环。

真实讯飞、在线 CI、MySQL 8 和 TTS 只有存在对应报告或链接时才能进入主讲口径。
