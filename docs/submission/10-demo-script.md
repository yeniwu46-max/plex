**演示账号**：`student001 / student123`；教师段切 `teacher001 / teacher123`

## 0:00–0:20 开场

- 一句话：PLEX = 对话建画像 + 多智能体多模态资源 + 教师审核闭环
- 点明挑战赛三项增强：流式交互、真多模态、演示链路修复

## 0:20–1:50 画像对话（流式）

1. 打开 `/student/me/profile`
2. 发送预设话术，展示流式回复 + 右侧 8 维卡片刷新

## 1:50–4:20 资源生成（时间线 + 多模态）

1. `/student/star-path/resources` 选择 `loop` 生成
2. 镜头对准 **智能体协作时间线** 逐步完成
3. 打开讲解（Markdown）、导图（Mermaid）、语音（播放 5 秒）、视频卡片/脚本
4. 一句收束：五类文本资源 + 语音/视频，满足多模态要求

## 4:20–5:40 驿站答疑

2. 展示流式 + Markdown 代码块

## 5:40–6:20 教师审核与路径

1. 切教师账号，资源审核页指出置信度/风险
2. 回学生端星轨，指出下一步路径

## 6:20–6:50 收束

- 创新点三句话：可解释画像、过程可见的多智能体、多模态且可降级
