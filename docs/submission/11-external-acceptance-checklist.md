# 外部验收清单

本清单用于关闭提交前仍依赖外部条件的闸门。任何本地规则、Mock 或静态截图都不能替代下列真实证据。

## 讯飞星火

- 配置 `IFLYTEK_SPARK_API_PASSWORD`，不得写入仓库或报告。
- 分别执行画像对话、五类资源生成、驿站问答真实冒烟。
- 报告记录模型名、请求 ID、延迟、实际后端和降级原因。
- 报告不得保存密钥、完整个人提示词或敏感输入。
- 三项真实调用均通过后，才能把 G1 标记为通过。

## GitHub 在线 CI

- 完成 GitHub CLI 登录并定位当前分支工作流。
- 确认 Python 3.12 Job 运行全量测试、知识库、安全、密钥和证据脚本。
- 确认 MySQL 8 Job 运行迁移冒烟与核心闭环测试。
- 确认 Node 20 Job 使用 `npm ci` 并完成生产构建。
- 归档工作流 URL、提交 SHA、Job 结论和 JSON artifacts 链接。

## MySQL 8

- 使用全新数据库执行全部迁移。
- 运行种子数据、登录、画像、资源生成、反馈闭环和教师审核。
- 保存数据库版本、迁移 head、测试结果和时间戳。
- 生成 `backend/reports/a3-next-stage/mysql-clean-environment.json` 后，才可关闭 MySQL 闸门。

## TTS

- TTS 当前不在主线实现和已完成声明中。
- 只有在真实服务接入、失败降级、权限和演示链路均验收后，才可写入正式功能清单。

## 提交前最终确认

- `release-readiness.json` 的 `submission_ready` 为 `true`。
- `delivery_gates` 中正式 PPTX 与七分钟 MP4 均通过。
