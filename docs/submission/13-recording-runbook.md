# 七分钟演示录制执行手册

## 录制前闸门

- `cmd /c start.bat --check` 返回 0。
- 后端全量测试、前端构建、bundle budget、密钥扫描通过。
- 演示数据库使用种子账号，不手工修改数据库状态。
- 浏览器缩放、分辨率、通知权限和网络条件固定。
- 主路线与离线备用路线各完整彩排两次。

## 镜头顺序

1. `0:00-0:35`：问题与闭环价值。
2. `0:35-1:20`：学生对话建立七维画像。
3. `1:20-2:20`：选择 `loop`，展示六角色生成五类资源。
4. `2:20-3:10`：展示差异、引用、置信度、实际后端和审核状态。
5. `3:10-4:00`：完成循环边界错误并形成错题。
6. `4:00-4:50`：接受画像建议，展示版本、路径和推荐变化。
7. `4:50-5:40`：展示前后测；同时展示样本不足错误态。
8. `5:40-6:25`：教师审核并验证学生仅看到已批准资源。
9. `6:25-7:00`：管理员健康、安全、性能和真实状态口径。

## 必须录入画面的证据

- 画像字段来源、置信度和版本号。
- 五类资源与生成任务步骤。
- 实际后端字段，不隐藏 `local_rules` 或降级原因。
- 接受与拒绝建议的不同结果。
- 教师审核说明和学生可见性变化。
- 学习效果证据数量与 `insufficient_evidence` 状态。
- 健康、安全、性能和冻结闸门结果。

## 失败处理

- 真实模型失败时展示失败原因和可恢复状态，再切换到明确标注的本地规则备用路线。
- 不剪辑出“实际后端”“降级原因”或审核状态。
- 不使用 Mock 截图替代真实操作。
- 单步失败后从该轮起点重录，不拼接相互矛盾的数据状态。

## 归档

- 保存原始录像、最终 MP4、录制日期、Git 提交 SHA 和使用的报告版本。
- 最终视频必须小于赛题平台限制；压缩前保留高码率母版。
- 视频中的指标必须与最终 PPT、README 和 `release-readiness.json` 一致。
