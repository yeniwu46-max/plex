# PLEX A3 正式交付文档

本目录是比赛提交材料的唯一文档入口。所有指标和功能表述必须能回溯到
`backend/reports/`、自动化测试、运行中的接口或明确标记的外部验收记录。

状态口径：

- **已验收**：真实运行环境或真实外部服务已执行并留存证据。
- **本地验收**：SQLite、本地规则后端或确定性测试通过。
- **外部阻塞**：代码已准备，但缺少凭证、联网 CI 或 MySQL 8 运行证据。
- **未实现**：不得在答辩中表述为已完成功能。

文档编号 01 至 10 分别覆盖需求、设计、多智能体、知识库与评测、测试、部署、
用户手册、开源与 AI 工具、创新价值和七分钟演示脚本。
