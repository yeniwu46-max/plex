# 创新点与应用价值说明

**版本日期**：2026-07-29（挑战赛优化版）

我们面向真实教育场景，构建了一个由学习者画像、资源生成、路径规划、学习交互、过程评价和教师审核共同组成的可追踪、可解释、可干预的个性化学习闭环。相比传统 AI 教育产品“问答式辅助”的单点服务，PLEX 更关注学习过程本身，通过数据驱动与多智能体协同，实现从提供答案到支持成长的转变。

## （1）可解释的八维动态学习画像

传统学习系统通常依据一次测试或简单行为数据分类用户。PLEX 构建八维动态画像（专业背景、知识基础、学习目标、讲解偏好、易错模式、学习节奏、兴趣方向、认知状态），同步保存字段来源、证据、置信度与历史版本，并能回答“为什么这样判断”。学生可通过自然语言对话更新画像，低置信度条目需确认后写入，形成“系统分析—学生反馈—模型优化”的双向机制。

**挑战赛增强**：画像对话页重新挂入学生端路由；确认回复支持 SSE 流式输出；右侧八维卡片随对话实时高亮刷新，演示链路完整可走查。

## （2）多智能体资源生产且过程可追溯

PLEX 将多智能体协作结构化管理：画像解释 → 知识检索 → 教学设计 → 资源生成 → 质量审核 → 路径规划。系统不仅保存最终资源，还记录每个智能体的任务目标、输入摘要、输出摘要、耗时与错误。前端以**智能体协作时间线**实时展示各步状态，使“多智能体”从黑盒变为可查看、可评价的生产流程。

主路径为自研顺序编排；CrewAI / LangGraph 作为可选增强（失败可降级），答辩口径与实现对齐。

## （3）多模态个性化资源，而不只是“多写几段文本”

针对同一知识节点，系统生成讲解文档、思维导图（Mermaid 可视化）、分层题库、拓展阅读、代码实操，并在挑战赛中补齐：

- **语音讲解**（TTS：讯飞优先，Edge / 本地 SAPI 兜底）；
- **教学短视频**（火山方舟 / SeeDance 类模型；失败保留分镜脚本）；
- 全站 **Markdown 渲染**（代码高亮、公式、导图），告别纯文本气泡。

资源难度、表达方式与案例背景由画像约束，实现“同一知识点、不同学生看到不同材料”。

## （4）教师参与的智能审核机制

面对生成式 AI 可能出现的知识错误、引用异常与安全风险，PLEX 采用“AI 初筛 + 教师审核”。低置信度、异常引用或风险项进入教师审核流，未批准资源不会进入学生正式列表，避免不可控的全自动发布。

## （5）证据驱动的学习效果评价

评价结合知识点掌握、作答记录、错误类型与干预节点；证据不足时主动降低结论强度（`insufficient_evidence`），避免“看似智能、实无依据”的反馈。

## （6）面向真实课堂的可靠性工程

离线规则降级、任务幂等、过期任务恢复、三角色权限隔离、课程安全（注入 / 敏感 / 越界）与引用校验，使系统既能在竞赛演示环境稳定运行，也能在网络抖动时优雅降级。

## （7）挑战赛相对初赛的体验跃迁（新增）

| 维度 | 初赛短板 | 挑战赛补齐 |
| --- | --- | --- |
| AI 交互 | 整包等待、剥离 Markdown | SSE 流式 + Markdown/Mermaid |
| 多模态 | 仅有文稿 stub | 可播放音频 + 视频卡片 + 答疑图解 |
| 演示走查 | 画像对话页断链 | 路由恢复 + 实时画像卡片 |
| 协同可见性 | 后台流水线不可见 | 智能体步骤时间线 |
| 提交完整性 | PPT/视频未入提交包 | 成片与文档一并打包 |

总体而言，PLEX 的创新价值在于把人工智能从工具型助手转变为教育过程协同伙伴：可解释画像、多智能体协作、多模态资源、教师审核闭环与证据驱动评价，构成面向智慧教育场景的可信 AI 学习系统。
