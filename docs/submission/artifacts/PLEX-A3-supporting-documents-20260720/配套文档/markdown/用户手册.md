# 用户操作手册

**版本日期**：2026-07-29（挑战赛优化版）

## 1. 快速启动

1. 解压提交包后，Windows 双击 `一键启动.bat`（或仓库根目录 `start.bat`）。
2. 浏览器打开 `http://localhost:5180`。
3. 仅检查环境：`一键启动.bat --check`。

## 3. 学生端推荐演示路径（7 分钟）

### 3.1 对话式画像构建（约 90 秒）

1. 登录学生账号 → 侧栏进入 **我的** → **学习画像**（`/student/me/profile`）。
2. 在左侧对话区发送示例：
   > 我是计算机专业大二学生，Python 刚入门，想期末前掌握循环和函数，喜欢看例子学习，每天能练 25 分钟。
3. 观察：回复**流式出现**、Markdown 排版；右侧 **8 维画像卡片**实时高亮更新。
4. 若出现“不太确定”的条目，点击 **确认更新**。

### 3.2 多智能体资源生成（约 150 秒）

1. 进入 **星轨学习** → **个性化资源**（`/student/star-path/resources`）。
2. 选择知识点（如 `loop`），点击生成。
3. 观察顶部 **智能体协作时间线**（画像解释→检索→设计→生成→审核→路径）逐步点亮。
4. 生成完成后依次打开：
   - 讲解文档（Markdown + 代码高亮）
   - 思维导图（Mermaid 可视化）
   - 语音讲解（`<audio>` 播放器；无云端密钥时为本地语音兜底）
   - 教学短视频（配置 Ark 密钥后可播放；否则展示分镜脚本）

### 3.3 驿站流式答疑 + 图解（约 90 秒）

1. 进入 **驿站助手**（`/student/messenger`）。
2. 提问：`用一个例子讲讲列表推导式`
3. 观察逐 token 流式回复与 Markdown。
4. 若提问含“图解/示意图”等词，且已配置图像模型，会出现图解卡片。

### 3.4 学习路径与效果（约 90 秒）

1. 星轨页查看个性化路径与下一步行动。
2. 完成一道试炼题，打开试炼页悬浮小E 查看辅导。
3. 成长档案查看雷达图与阶段分析。

## 4. 教师端

1. 登录 `teacher001`。
2. **领航总览 / 星域观测**：班级掌握度与风险。
3. **资源审核**：查看风险原因、置信度与引用；批准或驳回。未批准资源不会进入学生正式列表。
4. **试炼中枢**：发布班级试炼。

## 5. 管理端

1. 登录 `admin`。
2. 查看健康状态、任务成功率、模型后端、降级比例与风险分布。
3. 知识库管理仅管理员/教师可写。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 对话走规则兜底、非流式大模型 | 检查 `DEEPSEEK_API_KEY` / 讯飞凭证，以及本机代理（`LLM_HTTP_PROXY`） |
| 语音只有文稿没有声音 | 本地 SAPI 兜底应可出 WAV；也可配置 `IFLYTEK_TTS_*` |
| 视频只有脚本 | 配置 `ARK_API_KEY` + `ARK_VIDEO_MODEL` |
| 图解不出现 | 提问需含“图/示意”等词，并配置 `ARK_IMAGE_MODEL` |
