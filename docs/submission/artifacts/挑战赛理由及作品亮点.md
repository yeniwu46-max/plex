# 参加挑战赛理由及作品亮点

**作品名称**：PLEX（个性化学习多智能体系统）  
**赛题**：A3 高等教育个性化学习资源多智能体系统  
**版本日期**：2026-07-29  
**提交类型**：挑战赛（复活赛）优化作品

## 一、参加挑战赛的理由

初赛作品在画像建模、多智能体资源流水线、路径规划、安全审核与本地评测方面已具备较完整底座，但对照赛题明文要求与评分权重，存在几处“门面级”短板，直接影响评委走查与演示观感：

1. **演示材料未进入提交包**：PPT / 演示视频实体文件未同步进初赛源码包，对应评分项损失明显。
2. **非功能条款踩空**：赛题点名的流式输出、Markdown 渲染、多模态内容卡片化在初赛中基本缺失。
3. **多模态硬伤**：语音讲解仅有文稿 stub，无视频/图像生成链路；与“多模态教学资源”叙事落差大。
4. **画像对话演示断链**：后端能力完整，但前端路由未挂载，评委按赛题清单走查时第一条核心功能走不通。

因此我们申请参加挑战赛，用三天集中补齐上述短板，让已有的工程底座真正“看得见、讲得清、演示得出”。

## 二、挑战赛相对初赛的优化清单

| 优化项 | 初赛状态 | 挑战赛结果 |
| --- | --- | --- |
| SSE 流式对话 | 全站 `stream=False` | 驿站 / 画像对话支持 SSE，逐 token 渲染 |
| Markdown 渲染 | 纯文本并剥离星号 | markdown-it + 代码高亮 + KaTeX + Mermaid |
| 画像对话页 | API 有、路由无 | `/student/me/profile` 恢复，8 维卡片实时刷新 |
| 语音讲解 | 仅 transcript | TTS 合成可播放音频（讯飞 / Edge / 本地 SAPI） |
| 教学短视频 | 无 | `video_lesson` 类型 + 视频卡片 / 分镜脚本降级 |
| 答疑图解 | 无 | 关键词触发文生图卡片 |
| 生成进度 | 仅进度条 | 智能体协作时间线可视化 |
| 需求/创新/手册文档 | 偏薄或断链 | 补“新时代大学生×前沿AI”专章，手册可走查 |
| 提交包完整性 | PPT/视频缺失 | 文档、演示材料与源码一并打包 |

## 三、作品核心亮点（答辩可强调）

1. **完整的个性化学习闭环**：对话建画像 → 多智能体生成多模态资源 → 教师审核 → 路径推送 → 试炼反馈 → 效果证据。
2. **多智能体过程可见**：六步流水线 + 前端时间线，不是“黑盒一次出结果”。
3. **现代 AI 产品交互**：流式、Markdown、多模态卡片，符合赛题非功能要求。
4. **可信与可降级**：课程安全、引用校验、审核门禁；外部模型不可用时本地规则 / 本地 TTS 仍可演示。
5. **口径诚实**：CrewAI/LangGraph 为增强层；外部视频/图像依赖配额，失败不虚报。

## 四、建议演示顺序（≤7 分钟）

1. 画像对话流式构建（90s）  
2. 资源生成 + 智能体时间线 + 语音/视频卡片（150s）  
3. 驿站流式答疑与图解（90s）  
4. 路径 / 试炼 / 教师审核快切（90s）  
5. 创新点与开源说明收束（30s）

## 五、结语

挑战赛版本没有推倒重来，而是在扎实底座上补齐赛题明文要求与演示闭环。我们希望评委按“能否走通赛题故事线、多模态是否真实可感、交互是否符合现代 AI 规范”重新审视本作品。
