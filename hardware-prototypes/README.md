# PLEX 小 E 数字原型

本目录保存建模源码、设计说明、预览图和验证记录。完整可编辑模型和打印几何作为 [GitHub Release 附件](https://github.com/yeniwu46-max/plex/releases/tag/hardware-2026-10-07) 提供：

| 版本 | 下载文件 | 用途 |
| --- | --- | --- |
| v0.1 | `PLEX-XiaoE-v01.zip` | 外观评审、可编辑 Blender 场景及整体 STL |
| v0.3 | `XiaoE_v03_EDITABLE_SOURCE.zip` | 可编辑装配场景与生成源码 |
| v0.3 | `XiaoE_v03_PRINT_PACKAGE.zip` | 分件 STL、3MF 和打印交接资料 |

v0.1 是外观展示模型；v0.3 是四关节机械装配试样。两版均尚未完成实物打印、电子部件装入或可靠性验证。打印前请阅读各版本的 `README.md` 并先做配合试片。
