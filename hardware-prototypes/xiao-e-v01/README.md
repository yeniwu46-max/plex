# PLEX 小 E · 展示初模 v0.1

依据用户提供的角色设定图制作，日期：2026-09-17。使用 Blender 5.1.1 原生 Python 接口建模。

## 打开哪个文件

- `XiaoE_v01_editable.blend`：主要交付文件。保留 50 个外观部件、材质、灯光、四个相机，以及打包进文件的原始参考图。用于继续调整形象。
- `XiaoE_v01_print-study.blend`：融合后的单色打印研究模型。用于查看实际 STL 对应的整体几何。
- `XiaoE_v01_160mm_print-study.stl`：毫米单位，整体模型与底座连在一起，供切片评估和后续试打准备。
- `previews/hero.png`：彩色三分之四视角预览。
- `previews/front.png`、`side.png`、`back.png`：正交视图。
- `previews/print-study.png`：融合后的单色模型预览。
- `mesh-audit.json`：Blender 内网格检查记录。
- `stl-export-audit.json`：对实际导出 STL 的独立检查记录。
- `build_xiao_e.py`：可复现建模脚本；需 Blender 运行。
- `validate_stl.py`：STL 检查脚本；需 Python 与 NumPy。

## 造型取舍

保留大头白色头盔、黑色圆角面罩、青色 `> <` 表情、双侧圆环耳部、头顶装饰、披风、领扣、胸前和披风背部的四角导航星。

将悬浮姿态调整为双脚落地，并增加圆形底座。简化手部、关节、披风褶皱和头顶装饰；表情和徽记均为真实凸起几何，不仅是材质贴图。披风约 2.8 mm 厚，边缘配色采用独立的几何饰条。

本版用于外观评审。头部、身体和披风等在可编辑文件中分对象保存，但并未做成具备装配间隙的独立打印零件。内置灯效只是渲染材质，不代表硬件发光。

## 尺寸与数字检查

- 含底座总高：160 mm。
- STL 整体宽约 100.30 mm，前后深约 91.53 mm。
- Blender 单位：公制，单位比例 0.001，即一个坐标单位为 1 mm；正面为 -Y，Z 向上。
- 融合模型：1 个连接整体，0 条非流形边。
- 用 0.30 mm 体素融合重叠部件，并移除两个约 0.2 mm 尺度的孤立网格碎片，具体边界记录在审计 JSON 中。
- STL 不包含颜色；彩色外观保留在可编辑 `.blend` 中。

## 打印前仍需完成

打印机型号、材料和最终工艺尚未确认。本版未进行实际切片或实物试打，也未验证最小细节、支撑可拆除性和运输耐久性。数字网格闭合不等于已经完成打印验证。

当前 STL 是整体闭合实体表面，尚未拆件、挖空或布置支撑。FDM 的内部填充由切片设置决定；若用于树脂打印并需要挖空，应先设计排液、清洗、固化通道，再安排支撑。重点检查面罩下沿、下巴、手臂和披风背面的悬垂。

不要直接把各彩色外观对象分别导出当作装配零件，它们之间存在有意的穿插。后续若要分件上色、多色装配或加入电子部件，需要另做结构设计。

## 复现

在当前电脑上运行：

```powershell
& 'F:\pm\blender.exe' --background --factory-startup --python '.\build_xiao_e.py'
python '.\validate_stl.py'
```

脚本会重新生成本目录的模型及预览。需要保留手工修改时，先把修改版另存为其他文件名。

参考：[Blender 官方 Python API](https://docs.blender.org/api/5.2/bpy.ops.wm.html)。实际文件由本机 Blender 5.1.1 执行和验证。
