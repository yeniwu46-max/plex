# 小 E 硬件版 v0.2：原理与选型约束

日期：2026-09-17。阶段：机电结构原理，尚非加工图、PCB 图或经过样机验证的设计。

## 已确认需求

- 真实电子显示屏；面部不能保留 v0.1 的实心面罩和凸起表情。
- 内部为空腔，保留必要的壁厚、加强筋、安装支座和承重骨架。
- 四个主动自由度：J1 转头、J2 点头、J3 左臂抬举、J4 右臂抬举。
- 双腿固定在底座；本版肘部、手腕固定。
- 本轮先交付原理图，未改动 Blender 模型或生成硬件外壳 STL。

## 1. 外壳与屏幕

面部结构按“开窗前框 → 外购 LCD → 独立承托支架 → 空心头壳 / 可拆后盖”安排。

外购显示屏在后续 CAD 中作为独立占位零件，仅用于空间与干涉检查；导出打印文件时排除。前框只保留窗口周围的材料。显示区不能被圆角装饰遮挡；壳体不能穿过玻璃、背光层、驱动 PCB 或连接器。

屏幕由支架承托和边缘软垫约束，使用可拆卸压条或厂家规定的安装部位固定。紧固力传给支架、定位边或 PCB 允许的安装位置，不能直接夹压玻璃。屏幕应能从后方取出，不被已装入的颈部机构锁死。

原理图采用 Waveshare 2.8inch Capacitive Touch LCD 作为“存在真实产品的尺寸参考”，并非已经锁定采购。厂商资料列出模块外形 73.06 × 50.54 mm、显示区 43.20 × 57.60 mm，屏幕横置时显示区为 57.60 × 43.20 mm。接口为 SPI，触摸为 I²C。本方案暂不使用触摸功能。

厂商要求该模块的供电与逻辑电平匹配，故候选电路统一以 3.3 V 供给此屏。若更换 HDMI、DSI 或 RGB 并行屏，控制器、接口、线束及供电方案都需重新核对，不能直接沿用 SPI 图。

尚待核实：模块完整厚度、连接器高度与插拔方向、玻璃与 PCB 的实际边界、安装孔/夹持部位、线束最小弯曲半径、实际电流。

头壳与躯干需要前后或上下分壳，并以螺钉连接。螺柱尺寸及是否用热熔螺母取决于材料和工艺；树脂件不能直接照搬 FDM 热熔嵌件方案。避免永久胶封维护口。

总高先以约 220 mm 作为空间研究起点。原 160 mm 方案并非被证明不可行，但其内部未完成排布验证；不能用等比例放大或抽壳代替机构设计。具体壁厚、接口间隙、轴承座配合和开窗尺寸在器件与打印工艺冻结后确定。

## 2. 颈部承重与两个转轴

### J1：转头

竖直 Z 轴。躯干骨架固定舵机和轴承座；转动平台携带 U 形架、点头舵机及头部。平台由轴承和轴向支撑定位，舵机通过金属舵盘及连接件传递转矩。

完整载荷路径：头部 → 点头耳轴/轴承 → U 形架 → 转台 → 转台轴承与轴向支撑 → 躯干骨架 → 固定腿支柱 → 底座。

轴承需要能约束相关径向、轴向负载与倾覆力矩。可以采用具有相应承载能力的转台组件，或按载荷设计有间距的轴承组合；不能仅画一个任意轴承符号就认为头部已经获得充分支撑。舵机轴不得成为唯一承重支点。

### J2：点头

左右 X 轴，跟随 J1 的转台一起转动。头部内部结构托架与两侧金属耳轴连接，耳轴由 U 形架上的轴承支撑。点头舵机固定在 U 形架上，驱动托架转动。屏幕支架与承重托架分开，避免头部载荷压在显示屏上。

使转轴尽可能接近“头壳＋屏幕＋支架＋随动线束”的总重心，减少持续保持力矩。轴线同轴度、轴向游隙和转动摩擦应以局部测试件验证。舵盘花键使用对应舵机的成品金属件，不依靠普通打印件直接复制花键承载。

原理图没有指定可直接加工的联轴器、孔距或轴承型号。这些必须随舵机输出轴、支架跨度和负载一起设计。

## 3. 肩关节、披风与线束

J3/J4 为左右镜像机构，肩轴沿躯干前后 Y 方向，完成正视图中的侧向抬臂。舵机固定在躯干骨架，空心手臂连接旋转支架，采用独立轴承/衬套和轴向定位，避免仅靠舵机塑料输出轴悬挂手臂。

披风固定在背部，肩部留缺口，按手臂整个运动范围检查扫掠体积。披风不跨接两个相对运动的壳体，也不进入颈部与肩部间隙。需要保留工具进入紧固件的路径。

头部线束包含显示屏线和 J2 舵机线；不穿过实体舵机输出轴。优先采用轴旁通道与余量环，在固定侧和运动侧分别做应力释放，并避免线束同时承担拉力与扭转。图中蓝色虚线仅示走线方向，不表示已经验证弯曲半径。

## 4. 行程与控制边界

| 关节 | 运动 | 原理图中的拟定软限位 |
|---|---|---|
| J1 | 转头 | −45° 至 +45° |
| J2 | 点头 | −15° 至 +25° |
| J3 | 左臂外摆 | 0° 至 60° |
| J4 | 右臂外摆 | 0° 至 60° |

这些是待验证的设计目标，不是实际舵机行程、已验证角度或机械限位位置。正负方向在控制标定阶段统一。机械限位应位于软限位外侧且早于壳体碰撞、线束拉紧的位置。控制采用限速、限加速度的平滑轨迹；安装前先验证中位与行程。

需要位置舵机，而非仅用 PWM 控制转速的连续旋转舵机。普通 RC 位置舵机有内部位置控制，但图中的 PCA9685 不读取关节实际角度；上层系统没有外部关节闭环反馈。若后续需要确认是否到位、碰撞或卡滞，应增加编码器/位置反馈及电流检测，或改用带反馈的总线舵机并重新设计控制链。

## 5. 负载计算：先计算，后选舵机

点头与肩部最不利姿态需要评估：

`需求转矩 = 设计裕量 × (重力矩 + 转动惯量 × 角加速度 + 摩擦矩 + 线束阻力矩)`

重力矩为 `m × g × d`，其中 d 为重心到轴线的水平力臂；不是随意取头部半径。

举例仅用于说明方法：假设头部总质量 0.20 kg、最不利水平力臂 25 mm，则静态重力矩约 0.049 N·m（0.50 kgf·cm）。如果仅对这项采用 3 倍初步裕量，得到约 0.147 N·m（1.50 kgf·cm）；随后仍必须计入加速、摩擦与线束阻力，并检查实际供电条件下允许的工作转矩和热负载。这不能据此得出“堵转扭矩 1.5 kgf·cm 的舵机就够用”。

转头轴理想竖直时，重力不直接构成绕该轴的转矩；重点计算转动惯量、角加速度、轴承摩擦和线束扭转。头重仍决定轴承、支架及底座的承载要求。

不能把堵转扭矩当作可持续工作扭矩。若只有堵转数据，需要在台架上验证负载、温升、持续保持与动作占空比，或采用提供可用工作区间的执行器。尚未给出舵机采购型号。

## 6. 候选电气架构

采用 ESP32-S3 + SPI 显示模块 + PCA9685 + 四个位置舵机，作为可实现的功能框图。ESP32-S3 负责联网、表情和动作命令；学习推理留在 PLEX 服务端。语音、摄像头和电池系统不在这版已确认范围内，需增加时再核算。

| 连接 | 功能与约束 |
|---|---|
| PLEX ↔ ESP32-S3 | Wi-Fi；通信协议、设备认证与离线行为后续定义 |
| ESP32-S3 → LCD | SPI + DC/RST/背光等模块要求信号；3.3 V 逻辑 |
| ESP32-S3 ↔ PCA9685 | I²C；VCC 与上拉电压为 3.3 V |
| PCA9685 CH0–CH3 → 舵机 | 四路 PWM；检查所选舵机是否接受 3.3 V 高电平，必要时加合适的电平转换 |
| 逻辑稳压 → 主控、LCD、PCA9685 VCC | 候选独立 3.3 V 电源，按总负载及瞬态电流选型 |
| 舵机稳压 → 断电开关 → 独立配电 → 舵机 V+ | 电压按实际舵机额定值，6 V 仅为候选；大电流不经 MCU 或 PCA9685 芯片 |
| 全部模块 GND | 共地；舵机回流独立回到配电点，减少对逻辑供电的干扰 |

候选采用外部直流输入与独立稳压，图中 12 V 为架构示例。PCA9685 的 VCC 与舵机 V+ 是不同电源。图中舵机正电直接由外部分配，PCA9685 板上的 V+ 分配端可以不使用；不要把 VCC 误接到舵机正电。

PCA9685 是 PWM 发生器，并非电机功率驱动器。所选四个舵机应能兼容同一 PWM 频率；频率和脉宽范围按其资料与标定确定。控制启动时输出需处于禁用状态；若用 OE 做上电禁用，要处理所用板卡的默认 OE 下拉，而非假设接上一个上拉电阻即可可靠禁用。

ESP32-S3 开发板可选择 3V3 引脚供电，但必须与其他供电方式互斥，或按实际板卡设计隔离/电源切换。USB 调试时要核对 VBUS 与板上稳压器路径，不能未经核对叠加外部 3.3 V 与 USB 电源。

电源、线径、连接器、保险与开关额定值需要依据所选舵机的启动/堵转电流和可同时发生的最坏工况确定。逻辑供电容量同时覆盖无线峰值、屏幕背光和控制器；舵机瞬态负载不得使主控复位。配电点及器件附近的去耦、电容、反接和过流保护需在电路设计阶段落实。本图没有给出未验证的保险、电容或电源电流数值。

## 7. 下一阶段通过条件

1. 冻结实际屏幕、舵机、轴承、主控与接头型号，取得尺寸图或测量实物。
2. 建立真实器件包络、孔位、线束与装配路径，确认总尺寸及内部空间。
3. 单独打印颈部和肩部支架试件，验证同轴度、配合、限位与摩擦。
4. 用等效头部质量与重心做颈部台架实验，测保持、运动、温升与断电后的行为。
5. 用真实屏幕检查开窗、压条、排线和拆卸；用四舵机同时动作检查压降与主控稳定性。
6. 再建立完整空心壳体与可装配关节 CAD，完成干涉检查后导出分件 STL。
