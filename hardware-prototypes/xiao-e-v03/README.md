# 小 E v0.3：空心四关节通用装配试样

本版用于打印、装配和手动验证四个转动关节：转头、点头、左右抬臂。双腿固定于底座。屏幕和舵机尚未选定，因此这不是可直接装入任意屏幕、任意舵机的成品机器人。

**优先打开 `3mf/` 中的分件文件，使用实际打印机和材料配置切片。3MF 只有毫米单位的几何模型，不含打印机、温度、支撑或耗材配置。没有生成 G-code。** STL 也已提供，导入时必须选择毫米、100% 比例；不要用整体缩放调整轴承和螺孔配合。

## 文件与尺寸

| 项目 | 内容 |
|---|---|
| `stl/` | 31 类分件，每文件一个连续实体，已按初步打印方向放到 Z=0 |
| `3mf/` | 同样的 31 类零件，明确声明毫米单位；每文件只有一件 |
| `parts-list.csv` | 中文零件名称、数量、打印尺寸与备注 |
| `XiaoE_v03_assembly.blend` | 可编辑装配场景，四个角度控制；另行提供 |
| `XiaoE_v03_exploded.blend` | 拆解查看场景，不能整体导出打印；另行提供 |
| `previews/` | 装配、正视、拆壳、活动姿态、爆炸图 |
| `build_mechanical.py` | 制造几何源文件，用 Manifold CSG 构造实体后导出 |
| `geometry-audit.json`、`file-validation.json` | 几何干涉检查及导出文件复读验证 |

中立姿态打印件整体外接尺寸约 **128 × 124 × 234.5 mm（宽 × 深 × 高）**。头壳主体约 114 × 88 × 94 mm，底座直径 124 mm。所有单件按提供方向摆放，各轴包络不超过 124 × 124 × 54 mm；这不是整套零件同盘所需面积，还需留边、支撑及裙边空间。

外壳主体设计壁厚 3 mm；局部支座、接缝、夹紧槽、孔边及圆角处不同。面框为真正的 62 × 47 mm 开孔，头壳后方另有更大的安装开口。**没有屏幕、玻璃或眼睛的打印实体。** 托框与前面框后表面名义距离 10 mm；这只是当前装配试样位置，不能当作屏幕模块可用厚度保证。

## 先打印哪些

1. 先各打印一件 `21_bearing_fit_coupon` 和 `22_shaft_fit_coupon`，使用计划用于关节件的同一材料、方向和切片配置。
2. 轴承试片的 1–5 道刻痕分别表示直径 16.0、16.1、16.2、16.3、16.4 mm；钢轴试片分别表示 5.0、5.1、5.2、5.3、5.4 mm。实测后选择能装入、无明显晃动且无需强压的配合。孔位当前采用轴承孔 16.20、钢轴孔 5.20 mm；这是试样名义值，不是打印精度保证。
3. 先打印一个肩关节小总成：`15_shoulder_fork_L`、`16_arm_L`、两个 `17_shoulder_retainer_L_*`。验证轴承、钢轴、夹紧和轴承压盖，再打印其余大壳体。
4. 主装配件 `01`–`18` 共 25 个文件，每文件一件，左右件均需打印。不要把左右件当成重复文件删除。
5. `19_motor_adapter_template` 是可选空白转接模板，默认不必打印；不能视为四个已适配的舵机座。`20_screen_spacer_*` 是可选调距垫柱，按实际试装选择一种长度，不能把三种长度全部叠起来。

配合需要修改时：在 `build_mechanical.py` 中调整 `P['bearing_bore']` 或 `P['shaft_clearance']` 后重新生成。金属轴承和钢轴的参考尺寸保持 16 / 5 mm。不要缩放整个 STL，也不要靠拧紧螺钉强行拉入不合适的轴承。

## 切片交接要求

- 使用打印机制造商对应机型及所用材料的配置；温度、速度和流量目前未指定。
- 给定姿态是放置起点：壳体开口朝上，面框和压盖平放，U 架侧放。壳体内螺柱、横向孔、圆弧和台阶仍可能需要支撑；应逐层检查，并确认支撑能从开口拆除。
- 若采用 FDM、0.4 mm 喷嘴，可用 0.20 mm 层高、壳件 4 道壁、支架 5–6 道壁作为首次试片起点；填充比例与支撑由实际材料和切片预览确定。这些值未经本机试打验证。树脂/SLS 等工艺须重新安排支撑、方向和补偿。
- 打印颜色仅为预览建议：白色外壳、青色骨架、深色面框与底座。文件没有要求必须多色打印。
- 轴承孔、夹紧槽、螺母槽和螺钉座面需要清理并实测。M3 通孔名义 3.4 mm，六角螺母槽对边 5.8 mm，壳缝 0.4 mm。

## 装配顺序

1. 去除支撑和毛刺，完成孔径试片与单肩关节验证。先将封壳后不易触及的 M3 螺母放入对应槽。
2. 将两根固定腿夹在底座上盖与承重骨架之间；从盖板下方插入 8 根 M3×40 螺栓，装好骨架螺母。此时先不要把底座仓合上。
3. 左右肩叉固定到骨架。将两侧轴承、钢轴、活动臂依次装入，装压盖和端部轴环。轴环留合适轴向间隙，再夹紧活动臂；确认能抬臂且压盖螺钉不会碰臂。
4. 骨架转头座装上下两颗 625 轴承；插钢轴，装下轴环、上端内圈垫片及 U 架。调整轴向间隙后锁紧 U 架夹座，确认骨架不随转头一起扭动。
5. U 架两侧装点头轴承；将头托置于 U 架内，穿入横轴，装轴承压盖与端部轴环，夹紧头托。不要把压盖当作钢轴夹紧件。
6. 将头壳前后半分别固定到头托，安装顶部合壳螺钉。头部实心显示屏不存在，保持开孔；此阶段先不放电子模块。
7. 装独立面框和托框。通过 M3 螺杆、薄垫片及螺母定位；托框必须平行，不可靠压弯部件消除间隙。选定真实屏幕后，另做模块专用软垫与固定点，不能直接压玻璃。
8. 装躯干前后壳、后置披风。电子安装板在底座内单独固定，预留走线后再合上底座。
9. 手动检查四轴全过程：转头 ±45°，点头数学坐标 −15° 至 +25°，两臂各 0–60°。正点头角为前脸向下。先从小角度开始；这些角度是数字检查范围，模型没有物理硬限位，不是实物已认证行程。

## 电气与下一版边界

壳体、底座和腿是空腔结构，承重骨架占据部分内部空间，不是完全无遮挡的空盒。颈部线束应从轴旁留回旋余量，不从实心钢轴中心穿过；本版尚未建模真实线束、拖链、接头、应变释放件及运动硬限位。

四个机械转动轴已经建立，但本版**没有选定或安装舵机，也没有完成动力传动**。模板上的孔是再设计接口，不承诺与任何舵机耳孔或花键相配。选型后还要完成：舵机固定座、舵盘/联轴器或传动机构、线束固定、屏幕模块固定、驱动供电、扭矩与温升核算。不要用这一版的几何检查代替电机负载验证。

## 已检查与未检查

- 31 个 STL 与 31 个 3MF 逐一复读：封闭、单连通实体、法向一致、正体积、最低点 Z=0；3MF 的毫米单位及体积/边界与 STL 一致。
- 中立姿态的打印件两两体积交叠检查；简化金属件与打印件、金属件之间的交叠检查。
- 转头 19 个角度 × 点头 9 个角度，共 171 种头部姿态；每只手臂 13 个角度。5° 采样未检出超过报告阈值的刚体体积交叠，包含已建模的部分紧固件包络。
- 未做连续扫掠最小间隙证明、真实屏幕/舵机/线束装入测试、切片测试、实物打印、受力/疲劳/跌落/热分析。零件网格封闭不代表无需支撑，也不代表强度已验证。

## 重建

建模脚本使用 Python 3、NumPy、`manifold3d==3.5.3`、`trimesh==5.1.0`。可在隔离环境安装；当前工作目录的依赖仅在 `_cad_deps`，不随打印包分发。

```powershell
python -m pip install --target .\_cad_deps manifold3d==3.5.3 trimesh==5.1.0
python .\build_mechanical.py
python .\verify_print_files.py
& 'F:\pm\blender.exe' --background --factory-startup --python .\build_blender.py
```

本机以 Blender 5.1.1 构建；换机器时将最后一条命令的 Blender 路径换成实际位置。`.blend` 是分件网格装配文件，制造尺寸修改以生成脚本为准。

尺寸与制造参考：[NSK 625 轴承尺寸](https://www.nsk.com/in-en/engineering/products/bearings/ball-bearings/deep-groove-ball-bearings/extra-small-ball-bearings-and-miniature-ball-bearings-metric-series/625-esm-md.html)、[Prusa：面向 3D 打印的建模](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)。文中的试片、公差和切片起点属于本项目假设，仍需实际工艺验证。
