# 项目状态与真实性边界

| 项目 | 状态 | 说明 |
|---|---|---|
| 产品需求 | 已形成候选方案 | 场景、交互和隐私边界已定义 |
| BOM | 已形成估算 | 价格为 2026 年内部估算，不是采购发票 |
| 接线设计 | 已形成开发板级连接表 | 未制作正式原理图和 PCB |
| 固件 | 骨架代码 | 未在真实硬件上编译和运行验证 |
| 后端接口 | 提案 | 当前 PLEX 后端尚未提供硬件设备 API |
| 工业设计 | 未完成 | 无正式 3D 模型、结构件和模具 |
| 实物样机 | 未完成 | 无可提交实物照片 |
| 安全/可靠性 | 未完成 | 无 EMC、电气安全、跌落或连续运行报告 |

## 下一步最小验证

1. 采购 1 套开发板和模块，在面包板完成联网、按键和屏幕验证。
2. 先使用本地测试服务接收匿名事件，再对接 PLEX 测试环境。
3. 完成 72 小时连续运行、断网重连、令牌失效和重复事件测试。
4. 经学校授权后，在不采集真实身份的课堂中做 10—20 人次可用性测试。
5. 通过评审后再决定是否绘制 PCB 和制作 10 台小批量样机。
