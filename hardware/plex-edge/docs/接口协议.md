# PLEX Edge 接口协议（提案）

> 本文档描述拟新增接口，当前 PLEX 后端尚未实现。路径和字段需在正式开发前通过 API 契约评审。

## 1. 设备事件

`POST /api/v1/hardware/events`

```json
{
  "device_id": "plex-edge-lab-a-001",
  "session_id": "course-2026-fall-python-01",
  "event_id": "01JEXAMPLE0000000000000000",
  "event_type": "need_help",
  "occurred_at": "2026-08-31T10:15:20+08:00",
  "anonymous": true,
  "firmware_version": "0.1.0"
}
```

响应沿用 PLEX 统一格式：

```json
{
  "code": 0,
  "message": "事件已接收",
  "data": {
    "accepted": true,
    "duplicate": false
  }
}
```

## 2. 幂等与重试

- `event_id` 在同一租户内唯一；重复提交返回 `duplicate: true`。
- 设备使用指数退避，最大重试间隔 60 秒。
- HTTP 401/403 时停止重试并请求重新注册；4xx 参数错误不得无限重试。
- 事件缓存设置上限和保留期限，禁止无限占用 Flash。

## 3. 安全要求

- 仅允许 HTTPS；生产环境校验服务端证书。
- 设备令牌必须可吊销、可轮换并设置有效期。
- 后端按租户、设备、课程会话校验权限。
- 日志不得输出 Wi-Fi 密码、访问令牌、NFC 原始标识或个人学习数据。
