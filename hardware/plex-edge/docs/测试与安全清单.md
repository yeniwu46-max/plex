# 测试与安全清单

## 固件与联网

- [ ] 固件可在指定 ESP32-S3 开发板编译并烧录。
- [ ] 首次启动、Wi-Fi 失败、DNS 失败、TLS 失败均有明确提示。
- [ ] 断网事件可排队，恢复后按序发送且不重复。
- [ ] 72 小时连续运行无死机、内存持续增长或 Flash 写入异常。
- [ ] 令牌过期/吊销后设备停止发送并进入重新注册流程。

## 交互

- [ ] 按键消抖，长按和连续触发不会生成重复事件。
- [ ] 屏幕字体、对比度和提示适合教室光线。
- [ ] 蜂鸣器默认关闭，不影响课堂秩序。
- [ ] 匿名求助不携带可识别学生的数据。

## 电气与结构

- [ ] 使用具有合规标识的 5V 电源，外壳无裸露导体和锐边。
- [ ] 模块逻辑电平匹配，供电和峰值电流满足要求。
- [ ] 完成温升、短路保护、插拔和跌落测试。
- [ ] 正式销售前完成适用的 EMC、电气安全和环保要求评估。

## 数据与合规

- [ ] 学校书面确认数据范围、目的、保存期限与角色权限。
- [ ] NFC 标识经校内网关映射，不上传原始卡号。
- [ ] 设备日志经过脱敏，后台操作可审计。
- [ ] 可远程吊销设备并删除其未发送缓存。
- [ ] 未经授权不得采集真实课堂或学生数据。
